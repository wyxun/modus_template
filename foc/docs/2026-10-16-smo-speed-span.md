# SMO 速度估计 1 ms 单项试验

本轮仅完成代码、主机验证和 G431 构建，未连接 MCU、烧录、复位或启动电机。默认 `make.bat auto` 已包含本修改，无需附加构建参数。

## 依据及目标

上一版反电势四路采集 `smo-bemf-160-a.csv` 共 133568 点，无缺口、非有限值或设备/RTT 丢样。160 电 Hz 稳速段，反电势矢量最小半径约 0.193 pu，未见过零塌陷；偏心约基波的 1.6%～2%，椭圆轴比约 1.01。由传输后的反电势重建角度，其误差均在千分位截断的理论界内，未发现额外角度提取错位。

但逐拍角度差分会放大角度波动，阻断连续接管资格。此前离线 CSV 的 1 ms 差分较短间隔差分明显稳定；CSV 为 10 kHz，不能据此直接证明 MCU 内部 20 kHz 速度估计或故障响应已经合格。

本试验只验证延长速度估计跨度能否减少这种资格阻断，不宣称已解决 SMO 角度本身的毛刺或模型扰动。角度、反电势和电流观测器递推不变，不加入角度低通、PLL 或超前补偿。

## 修改内容及边界

`foc_smo.c/.h` 中，将逐拍角差乘速度系数，改为逐拍累积相邻角增量，每 N 个间隔输出一次平均速度，其余拍保持最近结果。

- 默认 20 kHz 下 N=20，跨度 1 ms。第一拍建立角度历史，20 个有效增量后才发布第一份速度，之前为零。
- 角度和反电势每拍输出。相邻角增量逐拍按半圈环绕处理，因此整个窗口超过半圈仍可正确累计；每拍增量小于半圈的既有限制仍存在。
- N 和 `1/(N*Ts*baseHz)` 在初始化预计算。N 为最接近 1 ms 的整数拍数，限制在 1～32；高于约 32 kHz 时窗口短于 1 ms。32 拍上限将恶意跳角下的角差累加限定在 ±16 圈以内，避免 FIXED 累加溢出，不引入环形缓冲或宽整数热路径。
- 保持配置结构、函数签名、输出单位、ADC 标度、采样/PWM 拍关系和四路波形不变。没有新增公共调试 API、诊断缓存或通用估计框架。
- 零反电势、Reset、FLOAT 非有限输入清除窗口及保持速度；空输入/空缓冲/空输出参数错误也清除动态历史，防止恢复时沿用出错前的速度。
- FIXED 沿用现有角差 Q15 量化，不改变基础数值函数；逐拍截断会产生小量偏置，试验不能替代定点量化误差评估。

## 保护响应的真实变化

Position 的门槛、连续资格拍数、滤波器、角度跳变检查、反电势检查、超时和 PWM 逻辑均未修改。原来的速度偏差检查仍然执行，但输入速度现在是窗口均值，不能再称为瞬时速度。

20 kHz 下，速度输出最多保持 1 ms；真实速度阶跃可能污染一个跨越阶跃的窗口，要到下一个完整窗口才完全反映，最迟约 2 ms。平滑斜坡的等效滞后还包含窗口平均和输出保持；原有 Position 速度滤波另有延迟。仅靠速度的短暂异常可能被平均削弱，这是需要台架评估的取舍，不能声称所有保护延迟不变。

角度本身未平滑，原有角度跳变保护仍检查逐拍角度；本次没有用平均角度掩盖跳角。无效输入和零反电势在当前调用立即清零输出。

## 主机验证

新增 `foc_smo_speed_span_test.c`，测试直接调用真实 SMO 私有角度/速度提取内核，使用已知反电势矢量。仅测试文件包含实现，不向固件增加测试入口。

先在旧代码上运行，恒速叠加 ±0.72° 相位扰动的速度容差断言失败；修改后 FLOAT/FIXED 均通过。覆盖：

1. 160 电 Hz、400 Hz 基值，速度应为 0.4 pu；相位扰动仍逐拍出现在角度中，窗口速度误差小于 0.003 pu。
2. 正反转、跨圈及窗口总位移 0.8 圈，验证没有端点半圈差分混叠。
3. 加速和减速斜坡，限制相对于真实速度的跟踪误差；20 种窗口相位的速度阶跃，均在 40 拍内收敛到新速度容差。
4. 零反电势、Reset、空输入和 FLOAT NaN 后的清零及恢复；每次使用新输出对象，验证不依赖调用者保存上次输出。
5. 19.5 kHz 的非整数毫秒跨度、1 kHz 的单拍跨度和 40 kHz 的 32 拍上限。

原 SMO 数值、生命周期、滑模反馈、FIXED 初始化约束、软件 atan2、热路径约束均通过。Position 接管和位置边界 FLOAT/FIXED 通过，真实 App/Motor/Position/Core 八种组合通过。默认及替代四路波形配置、超过六通道编译拒绝、波形通道约束通过。

Position 测试中原有的“注入异常速度仍阻断资格”用例继续保留；该用例模拟 SMO 输出，不能用于宣称真实噪声输入现已完成接管。

C 行宽 82 字符及 `git diff --check` 通过。未 stage 或 commit，保留原有工作区变更。

## 20 kHz 开销与构建

每个 50 μs 周期新增一次标量加法、计数及分支，原速度乘法由每拍改为每 20 拍一次。没有新增三角函数、除法、动态内存、ISR 日志、通道数或波形采样率。FLOAT 目标反汇编确认累加使用 `vadd.f32`，窗口完成时执行 `vmul.f32`；角度仍使用原来的 `atan2f`。

反汇编与体积只能验证代码路径，不能换算为实机 ISR 最大耗时。上一版最高抽查为 44.7706 μs，距离 50 μs 仅余约 5.23 μs；新版本必须重测，而且需要覆盖实际接管、d 电流退出和闭环运行阶段，不能只测强拖阶段或用平均值验收。

## 烧录后验证

用户在工程目录运行 `.\make.bat auto`，恢复 RTT 后再授权短测。当前默认仍为 d 轴强拖→SMO 接管试验，不是编码器闭环。

先读取并固定 AS5600 SF3 / CONF0300；复用四路 `SMO_mT / Ealpha_ / Ebeta_m / EncAbs`，10 kHz，不增加 ISR 日志。与上一版相同方向、速度 0.4 pu（160 电 Hz）及空载条件比较，区分尚未接管的强拖段和已经接管后的段。

读取现有资格进度、状态及故障，检查是否通过资格、渐变及稳定运行；连续关注 ISR 最大值，测到过周期或余量不足立即停止并回退。检查 CSV 时间缺口、设备 drop、RTT full，丢样记录不能作为角差改善证据。

比较角差偏置、分布、尖峰和加减速跟踪，不以速度变平替代角度指标。此版本不会直接消除四路中 SMO 角度上的毛刺。是否真实完成接管、接管电流连续性、新版 ISR 开销、故障停机响应及丢样，全部仍待台架验证。
