# 强拖 d 轴场与 SMO 接管衔接修正

2026-10-16。本轮仅代码、主机测试与构建；未烧录、复位、连接调试器或启动电机。

## 依据与选择

上一版正向 160 电 Hz 强拖已实际运行稳定，但 SMO 相对强拖控制角约 +65.88°，超过 45°接管门槛；同一段 SMO 相对对齐校零后的编码器约 -6.48°。原程序将启动电流设为强拖坐标系的 Id=0、Iq=0.06 pu，其轨迹角不保证接近真实转子 d 轴角。对齐结束时还从固定 d 轴励磁改为了 q 轴电流指令。

本版选择改变启动旋转场的轴定义：强拖轨迹驱动正 d 轴场电流，Iq=0。转子在旋转场后方形成负载角，资格仍在原 45°门槛内检查。没有向 SMO 加 90°、66°等常量，没有扩大角差门槛，也没有修改 SMO、Position 融合、ADC 或采样时序。

该选择改变启动控制行为；不能假设实机旧 +66° 一定精确变成 -24°。实际负载角、启动可靠性和接管过程中是否掉速必须重新采集确认。

## 代码变化

- `motor.c` 对齐结束后把启动电流从 `{0, Istart}` 改成 `{Istart, 0}`。对齐到启动的场方向不再切换 90°，但对齐 0.04 pu 到启动 0.06 pu 的幅值变化仍然存在，由原电流环执行。
- 沿用 Position 原有资格计数、逐拍 0.5°最大角度修正和渐变预算，不改保护门槛。渐变期间 d/q 指令保持 `{Istart, 0}`；它在新坐标角下形成连续旋转的参考矢量，而非瞬间换轴。
- 接管事件仍使用原速度 PI 跟踪接口，以此前 q 指令（现在为零）接续。速度参考仍按原闭环规则变化。
- 接管后的速度环每个 tick 将 d 指令减小 0.0005 current pu，直到零。默认 1 kHz 下，0.06 pu 退出约 120 ms；FIXED 会因量化略有差异。该步长是独立的电流步长，没有复用速度步长的单位。
- d 电流尚未归零时，q 电流使用 `|Iq| <= min(IqMax, IphaseMax - Id)` 的保守范围。由 L1 上界保证 d/q 合成电流不超相电流限制，免于新增平方根；发生裁剪时沿用 PI Track 避免额外积分堆积。
- 启动配置要求速度 PI 的输出和积分区间均能表示零 q 接管初值；无法表示时初始化拒绝。
- 保持函数签名、结构体字段及尺寸。为避免调用方迁移，保留 `qStartupIqPu` / `qIqPu` / `MOTOR_CONFIG_STARTUP_IQ_PU` 原名称，并在声明处明确其现用途为启动场电流幅值，单位仍为 current pu。
- 未增加状态、缓存、公共函数、三角计算、除法或 ISR 日志。额外退出与限幅计算只在已有速度环 tick 执行，不宣称开销为零。

## 默认构建与观测

在 E:/Project/modus_template 运行 `.\make.bat auto` 即可构建并烧录本版，默认 G431/FLOAT/debug-rel，无需另选 HEX 或宏。上电不会自动运行。

启动目标仍为 speed 0.4 = 160 电 Hz；对齐 1.5 秒，升速 3 秒，连续资格 200 ms，融合基础权重 20 ms，RUNNING 未接管超时 10 秒。启动场电流仍为 0.06 pu（3.5 A 基值下 0.21 A）。

四路仍为 Ctrl_mT、SMO_mT、Iq_mpu、EncAbs，10 kHz。EncAbs 零位离线从本次对齐末段估计，且每次读取/确认 AS5600 SF=3。Iq_mpu 是当前控制坐标系的实测 q 电流，本版强拖阶段应接近零，不能用上一版 q≈0.06 的期待判断运行失败。场电流改在 d 轴，现有 motor status 可以检查 id/iq，不增加波形通道。

## 软件验证结果

1. 修改前新增 Motor 断言复现启动 d/q 指令不符合新契约的失败，修改后 FLOAT/FIXED 通过。
2. 位置测试保留 +66°不合格场景；在一个明确声明为坐标契约的 -24°样例中验证原门槛下的资格、跨零角度渐变、完成事件和新运行代次复位。该样例不是电机动力学模型。
3. 恒定 0.06 pu 场幅值下，新增角度修正造成的每拍额外参考矢量变化小于 0.000525 pu，幅值保持；该界限不包含轨迹本身的正常电角旋转。未把它当成实机电压/电流完全无扰动证明。
4. Motor 测试验证 q 无强制初值跳变、d 单调渐退且每个速度 tick 变化受限、最终归零，以及受限相电流预算下的 q 裁剪。还覆盖非有限/零/负启动电流、无法表示零的 PI 区间、接管丢失、clear 后重新启动和启动超时。
5. 真实 App/Motor/Core 组合八种矩阵通过：FLOAT/FIXED × 无观测器/SMO × 静态/动态编码器绑定，含实际启动 d/q 指令断言。
6. 原启动轨迹、位置接管、Motor break、参考边界、应用命令/四路默认与替代通道、超六通道编译拒绝、SMO 生命周期测试全部通过。
7. 构建 text/data/bss：FLOAT debug-rel 68860/592/18264；FIXED debug-rel 67820/592/18296；release 43484/420/5880 字节。相对上一版，FLASH text 分别增加 248/136/248 字节，RAM 不变。App 尺寸仍为 0x488，波形暂存仍为 16 字节。
8. C 行宽及 git diff --check 通过。没有 stage、commit 或覆盖此前已暂存内容。
