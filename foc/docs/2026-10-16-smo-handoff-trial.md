## 直接构建与烧录

在 E:/Project/modus_template 执行 `.\make.bat auto`，使用默认 G431 / debug-rel / FLOAT 即可，无需附加宏或替换 HEX。上电不会自动转动。用户烧录并恢复 RTT 后，由后续明确授权的台架操作启动。

## 本轮变更

- 默认位置源改为 HARD_DRAG，启用已有启动轨迹及 SMO 自动资格判断/渐变接管，不增加新的控制模块、公共函数或运行状态。
- 固定频率强拖设置为 0，采用启动轨迹；`motor speed 0.4` 对应 160 电 Hz、7 对极约 1371 rpm。这是试验目标，不是已验证的最低接管速度。
- 对齐 1.5 秒，随后 60000 个 ISR 步（20 kHz 下 3 秒）升速；启动 Iq 0.06 pu（3.5 A 基值下约 0.21 A）。
- 最低强拖速度门槛 0.4 pu；反电势门槛 0.13 pu、速度误差与角差等已有资格条件保留，连续资格 4000 步（200 ms）后开始渐变，权重过渡 400 步（20 ms）。角差修正步限和渐变总预算仍按既有逻辑执行，故实际完成时间还取决于修正进度。
- 从进入 RUNNING 起，200000 步（10 秒，包含 3 秒升速，不含对齐）内未接管，沿用位置故障和 PWM 关闭；渐变及接管后的失效保护保持。限流、启动超时、电压模型有效性和复位处理不变。
- 保留此前的 ADC 四次累加低位、476 counts/base、SMO 边界层与增益；本轮不再同时整定 SMO。

## 四路波形

| 通道 | 含义 |
|---|---|
| Ctrl_mT | 当前实际控制电角；接管前来自强拖轨迹，接管后来自已有观测器反馈路径 |
| SMO_mT | SMO 原始估计电角，不等同于控制侧的一拍预测角 |
| Iq_mpu | 现有控制输出中的 q 轴实测电流，PU |
| EncAbs | 独立编码器机械角乘极对数后的绝对电角；未减对齐零位 |

角度内部以圈表示，流协议按 1000 缩放；观察器或角度无效时使用 -1 标记。保持原 10 kHz、四通道、16 字节波形暂存空间，无 ISR 日志，无新三角计算。编码器 I2C 仍在前台，波形采样只复用现有缓存读取及时间外推函数。该读函数包含已有外推运算，不能仅凭代码体积宣称 ISR 开销不变。

EncAbs 不能直接与控制角作未校零的绝对角差比较。采集应覆盖启动对齐段，在对齐稳定末段估计常量零位偏移，离线扣除后比较；不把常量偏移当作 SMO 滞后。编码器仅作诊断参考，初始化失败或缺样输出无效标记，不注入控制反馈。无波形的 release 与 FIXED 构建不因诊断参考启用编码器。

## 烧录后验证顺序与未验证项

1. 先读状态，确认 IDLE、无故障、PWM 关闭和当前固件；读取 AS5600 配置并在停止状态设 SF=3、读回确认。固件没有声称已固定硬件滤波寄存器。
2. 先开四路采集，覆盖静止与对齐，再发一次 `motor speed 0.4`；本模式由启动函数自行对齐，不使用编码器 `motor calibrate` 作为启动条件。
3. 通过既有 `motor status` 的 position phase/qualified/blend 字段确认真实接管，而非凭两条角度接近判断。
4. 记录超时或保护原因，检查转向、升速跟踪、接管前后角差偏置/波动/尖峰、Iq 跃变和稳速误差。资格不满足则保留失败证据，不放宽门槛强行切换。
5. 用原有 ISR 计时记录检查 50 μs 周期及余量；同时检查 CSV 连续索引、空值和设备丢样计数。当前尚未实测本版 ISR 最大开销、丢样或接管成功率。上一版约 36.07 μs 的抽查值不能代替本版数据。
6. 首次短测完成后再安排重复启动、加减速和负载验证；当前未验证反转（既有无感启动入口只接受正目标）、热机重复性与长期稳定性。试验结束后回收临时参考通道配置。
