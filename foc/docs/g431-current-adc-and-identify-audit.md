# G431 三相电流采样与电阻辨识链路审计

## 此次能确定的事实

- 旧实现将 ADC1/2 配为 12 位左对齐、关闭过采样，但 MDI 将
  `JDR1/JDR2` 原样交给 Motor。`1390 counts / 3.5 A` 却是 12 位
  **右对齐**计数的标度。后续仅将三相 JDR 在 MDI 中右移 4 位，
  因此按当前源代码，原来的反馈高估 16 倍，修改后的读取与标度一致。
- 这次右移改动没有同时改变 `FOC_CURRENT_BASE_MILLIAMP=3500`、
  `FOC_CURRENT_COUNTS_PER_BASE=1390`、电压基准 12000 mV、
  identify 两档激励或电阻公式。align 给定则另从 0.1 降到
  0.005 pu；电机 L/SMO 参数也改过，但不参与 identify R 的公式。
- 最新日志中 `Id=0.0104/0.0252 pu`，差值约 0.0147 pu，即
  51.55 mA；`VdRef=0.15/0.30 pu`，差值 1.8 V。由这两个*软件量*
  得到 34.919 Ω 是算术正确的。它是约 2.55 Ω 规格的 13.7 倍，
  但不能据此再次乘/除以 16：电流 ADC 实际码、OPA 输出及电机
  端子实际电压还没有独立核对。`VdCmd` 是命令，不是电压测量。

## 统一的数据格式与物理换算

| 环节 | 新配置/换算 |
| --- | --- |
| U | ADC1 注入 rank1；rank2 仍采 U，使两 ADC 的 JEOS 时刻一致 |
| W / V | ADC2 注入 rank1 / rank2 |
| 过采样 | 每个注入 rank 4 次转换，硬件结果右移 2 位求平均 |
| ADC 存储 | ADC1/2 全部显式右对齐；JDR 与普通 DMA/DR 均为 0–4095 |
| MDI | U/V/W 与 VBUS/温度/电位器读取均不再额外右移 |
| 零偏 | PWM 禁用时在同一新格式下重新校准各相 offset |
| 相电流 | `(offset - sample) / 1390` pu；基值 3.5 A |
| D/Q | Clarke/Park 在上述 pu 计数上运行 |
| 辨识 R | `abs(ΔVd_cmd_pu / ΔId_pu) × 12000 / 3500 × 1000` mΩ |

20 mΩ 分流电阻、OPA ×16、VDDA=3.3 V **若均属实**，则
`4096 × 0.020 × 16 / 3.3 ≈ 397 counts/A`；3.5 A 约 1390
码。该式只验证系数的一致性，并不验证实板的分流值、VDDA、
OPA 闭环增益和相别映射。直流电源的输入电流不是相电流。
此前记录的约 41000 左对齐零偏相当于约 2560 个右对齐码，
即在 3.3 V 假设下约 2.06 V；它并非严格 1.65 V。因此所谓
`1.65/(0.02×16)=5.16 A` 只是理想中点偏置时的单侧范围，
不能代替本板实测的正负向余量。

## 安全激励与上板验收顺序

本次将 identify R 两档命令由 0.15/0.30 降为 0.02/0.04 pu。
在 12 V、2.55 Ω、静止且理想电压施加的假设下，约为
0.094/0.188 A；此前两档理论上达 0.706/1.412 A，超过
0.5 A 额定电流。该估算不能代替实测限流。

1. 烧录后先不启动 PWM。核对普通 VBUS ADC 仍约为台式电源值；
   核对三相 offset 位于 0–4095、稳定、彼此相近，并核对实际
   `CFGR.ALIGN=0`、`CFGR2.JOVSE=1`、`OVSR=4x`、`OVSS=2`。
2. 仅做短时、低压静止测试。用独立电流探头或串联电流表核对
   **相电流**和 ADC 差码，目标约 397 counts/A；同时测电机端
   的实际相电压/线电压，并与 `VdCmd` 换算值比较。不要把电源
   输入电流当作相电流。独立测量前不采用新 R 更新 PI/SMO。
3. 观察 `ADCtrig->CCR` 最大时间与 `bottomLate`。4×使两 rank
   转换时间由约 0.9 增到约 3.6 µs（42.5 MHz、每次 19 ADC
   周期估算）；要求 `bottomLate=0`，最小余量为正并保留数微秒。
4. 核对双档稳态电流、实际端电压、转子是否静止及温升后，再
   重跑低压 identify R。若 R 仍远离 2.55 Ω，优先区分
   “ADC 电流比例错误”与“实际施加电压小于命令”，不调 PI/SMO。

过采样只降低随机噪声；PWM 同步纹波、OPA 饱和、错误采样点、
电压模型和通道接线错误不会因此自动消失。
