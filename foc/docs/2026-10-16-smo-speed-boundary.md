# 接管最低速度边界修复与反电势诊断固件

2026-10-16。本轮只完成代码、主机验证与构建；未连接 MCU、未烧录或启动电机。

## 本轮落实的缺陷

上一轮已用真实 Position 模块复现：强拖 0.4 pu，原始估计 0.4 pu，滤波估计 0.395 pu，角差和反电势均合格时，可以完成资格和渐变；接管后却立即因滤波速度低于 0.4 pu 而丢失。

本轮采用单项行为修改：进入仍按强拖最低速度 0.4 pu 检查；保持最低速度按原有允许速度误差计算：

`hold_min = entry_min - entry_min * max_speed_error_ratio`

默认即约 0.36 pu = 144 电 Hz。其含义是保持下限覆盖资格阶段已经允许的滤波速度误差，并非重新宣布 144 Hz 已经通过实机可靠性验证。

乘法及减法只在初始化执行，接管后沿用原来的一次最低速度比较。没有新增公共参数或函数，原配置输入和 PU 单位不变。Position 内部保存一个初始化推导的保持门槛，不增加诊断缓存或状态机。

为了保持 FIXED 与资格误差计算的舍入一致，使用减去同一个允许误差的形式，而非另写一个独立的经验速度值。入口最低速度必须在 (0,1] PU 内；若 FIXED 下推导的保持门槛量化为零，初始化拒绝。

## 明确保留的条件

- 强拖进入最低速度仍是 0.4 pu，0.395 pu 强拖不会因为保持下限较低而获得进入资格。
- 资格角差 45°、滤波速度误差 ±10%、原始速度误差 ±15%、反电势门槛 0.13 pu、4000 拍连续资格、渐变预算不变。
- 接管后原始速度相对滤波速度的偏差、绝对速度有效性、角度跳变和反电势/无效输入保护不变。
- 未取消原始单拍速度检查，未加入 PLL、角度低通、经验超前或新无感算法。原始速度噪声仍未解决，当前工况仍可能无法进入接管。
- d 轴强拖、d 电流退出及电流预算限制、Motor 超时/PWM 安全逻辑、ADC 标度和采样拍关系均未修改。

## 软件证据

1. 先新增期望“合格速度接管后保持”的测试，旧代码在接管后第一拍失败；修改后 FLOAT/FIXED 通过。
2. 覆盖 0.395 pu，以及容差两端的 0.36 / 0.44 pu：在强拖 0.4 pu 时资格、渐变、保持均通过。
3. 保持阶段持续降至 0.35 pu，仍由原速度滤波及保持下限报告 OBSERVER_LOST；滤波响应时间不等于原始单拍即时保护，不能混淆两者。
4. 对已接管状态注入原始速度偏离、反向、弱反电势、无效样本、角度跳变、超量程速度，以及 FLOAT NaN，均继续报告失效。
5. 重新初始化后推导新的保持下限并清除接管进度；验证强拖低于进入下限、非法最低速度及 FIXED 零保持门槛拒绝。
6. 新增未解决噪声的特征回放：在 20 kHz、400 Hz 基值下，角增量交替 0.004/0.012 圈，平均与 0.4 pu 轨迹一致，相对角变化为 1.44°峰峰值；原始速度交替为 0.2/0.6 pu。连续运行 4500 拍（225 ms），既有滤波速度接近 0.4，但原始速度检查使资格始终为零。FLOAT/FIXED 均复现，证明本版没有偷偷绕过该阻塞点。
7. App/Motor/Position/Core 八种组合（FLOAT/FIXED、无观测器/SMO、静态/动态编码器）通过。位置边界、应用与默认/替代四路、超过六通道编译拒绝、Motor 速度、break、参考边界和 SMO 生命周期测试通过。
8. C 行宽、git diff --check 通过，未 stage 或 commit，保留原有改动。

相对上一份纯反电势诊断固件，text 分别增加 48/144/48 字节。Tracking 从 32 增至 36 字节，Position 从 204 增至 208 字节；G431 的 App 原有后续成员对齐空隙被吸收，App 仍为 0x488=1160 字节，总 bss 不变，波形暂存仍为 16 字节。

配置结构与函数签名不变，但 Position 内部成员偏移变化，不能照搬旧 Handoff 内存地址。后续读取必须从本次 ELF/DWARF 解析；当前 App 和既有 ISR 计时成员的位置经核对没有变化。

ISR 没有增加门槛计算的乘除，但这不是实机耗时证明。上一轮最高抽查 44.94 us、约余 5.06 us，仍不构成完整 WCET；此版尚无新耗时数据，尤其真实接管阶段未测。

## 默认烧录和后续验证

在 E:/Project/modus_template 直接运行 `.\make.bat auto`，无附加参数。默认 G431/FLOAT/debug-rel 已包含本修复及反电势四路诊断。

四路顺序仍为 SMO_mT、Ealpha_mpu、Ebeta_mpu、EncAbs，10 kHz，编码器前台参考轮询保留。没有增加控制角或 Iq 通道；这些状态仍可通过原 motor status 观察。Ealpha/Ebeta 是现有 SMO 滤波反电势状态，单位为电压 PU。

用户烧录并恢复 RTT 后，再确认 IDLE、PWM=0、fault=0 和 AS5600 SF=3 读回，按相同方向、speed 0.4 和负载做短采集。先检查四路连续索引及设备丢样计数，再检查反电势轨迹偏心、幅值近零、谐波/残差和 atan2 角重建。不要把“本次仍超时”误读为保持边界修复无效，因为原始速度资格阻塞尚保留。

只有补齐当前反电势证据后，再选择速度质量时间尺度的改法，并同时覆盖资格、渐变、接管后保护；不能仅因离线 1～2 ms 曲线好看就取消瞬态失效保护。
