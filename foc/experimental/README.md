# 实验算法

这里保留未接入 `foc.mk` 的独立算法：PLL、LTD、LADRC、SMC、STA、DOB、滤波器、PMSM 前馈和齿槽补偿。它们不属于框架 V1 的已验收能力，也不进入当前 ISR 或目标构建。无消费者的运行时 controller 适配层和 LADRC vtable 适配已移除。

接入前必须明确采样周期、PU 基值、输入输出单位、数值范围、状态归属与错误策略，并补独立数值测试。特别是 PLL 的速度目前隐含每拍圈数；前馈参数不能直接把物理电感当作执行系数。各算法继续使用自身明确类型和直接调用，不恢复通用运行时函数指针分派。

这些源文件仅做 FLOAT/FIXED 编译检查，不能据此声称算法数学、台架性能或硬件时序已经验证。
