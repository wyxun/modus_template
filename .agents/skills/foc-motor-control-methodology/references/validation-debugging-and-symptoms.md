
# FOC 验证、调试和故障现象

## 1. 推荐验证阶梯

每一级都要有通过条件；前一级不成立时，不要跳到更复杂的无感或弱磁问题。

### Level 0：模型和配置

检查电机类型、Y 等效、极对数、`Rs/Ld/Lq/Psi_r/J`、电压电流基值、坐标约定、PWM 极性、ADC 极性和限幅。用简单计算检查转矩、电压、电流和最高速度的量级。

### Level 1：PWM 和采样链路

先发安全的 50% 占空比或已知 PWM 模式，确认频率、互补输出、死区、刹车和比较值更新点。再做小电流直流实验，确认 ADC 偏置、相序、极性、归一化、 Clarke/Park 结果和电流限制。不要在采样链路未确认时闭合电流环。

### Level 2：仿真和离散时序

使用同一组电机参数分别运行连续、离散、PU、浮点和定点模型。模拟 ADC 触发、 DMA、计算、PWM 生效和采样延时。通过波形检查坐标变换、PI、限幅、观测器和 SVPWM，再把结果与代码变量一一对应。

### Level 3：编码器 FOC 基线

用编码器角度让电机低风险运行，先调电流环，再调速度环。记录 `Id/Iq`、电流参考、`Ud/Uq`、电压幅值、速度、转矩、母线和故障状态。编码器基线不稳定时，不要把问题归因于无感观测器。

### Level 4：观测器对比

观测器独立运行时，把估算角度、速度和编码器角度/速度对齐比较，检查稳态误差、动态滞后、方向反转、低速和带载。单看观测器内部状态或输出电压“看起来平滑”不足以证明角度准确；还要比较同速度同负载下的电流、功率和能力。

### Level 5：无感接管和性能扩展

定义收敛、有效、速度范围和超时条件后再从编码器切换到观测器。切换时处理角度补偿、积分器、参考电流和限幅连续性。最后才增加 I-f、HFI、MTPA、弱磁、过调制和降噪优化。

## 2. 证据优先的排查顺序

面对一个现象时，按以下顺序收集证据：

1. 复现条件：电机、母线、温度、负载、方向、速度、电流、模式和软件版本；
2. 采样原始值和偏置：确认 ADC 符号、GND、增益、饱和和通道映射；
3. PWM 时序：触发点、采样窗口、计算耗时、比较值更新和实际生效点；
4. 变换结果：相量、alpha-beta、dq、角度和速度，检查能量及正负号；
5. 环路状态：参考、反馈、误差、PI 输出、积分器、限幅和解耦项；
6. 观测器：输入电压/电流、磁链、PLL 误差、估算角度/速度和有效标志；
7. 功率级和机械结果：母线、电压、电流、转矩、温升、声音和负载能力。

## 3. 常见症状矩阵

| 症状 | 优先怀疑 | 先看什么 | 最小实验 |
|---|---|---|---|
| 静止电流不为零 | ADC 偏置、极性、坐标零点 | 原始三相 ADC 与偏置 | PWM 关闭采样并重复校准 |
| `Id/Iq` 极性反了 | 相序、Park 角度、编码器方向 | 相序、角度增量、变换输出 | 低电流正负旋转对比 |
| 电流环高频抖动 | 采样噪声、带宽过高、延时或饱和 | 参考/反馈/PI/电压幅值 | 降低带宽并固定采样点 |
| 电流环慢且有明显滞后 | 带宽过低、执行周期错误、滤波过重 | 实际 `Ts`、阶跃上升时间 | 记录上升时间并校正离散参数 |
| 高速无感失步 | 电压重构角度、PWM 延时、参数误差 | 电角速度、重构电压角度、PLL 误差 | 仅改变电压角度补偿并仿真对比 |
| 低速带载差 | `Rs` 温漂、死区、反电势信噪比、观测器偏置 | 实际电压、死区、磁链幅值、负载 | 编码器基线与低速无感对比 |
| 扇区切换电流突变 | 采样窗口、单电阻重构、比较值更新 | 扇区、采样值、移相前后占空比 | 固定扇区低速测试再跨扇区 |
| 单电阻波形异常 | 极性、双更新、采样窗口不足、移相过度 | 开关状态、测量相、ADC 采样时刻 | 逐个扇区验证采样表 |
| 高频注入噪声大 | 注入幅值、频率接近可听频段、规律性过强 | 注入电压、电流幅值和频率 | 降幅、换频、再比较角度信噪比 |
| 速度环振荡 | 外环过快、速度滤波延迟、`Iq` 限幅 | 速度误差、滤波输出、`Iq` 饱和 | 暂时固定电流限幅，逐步降低带宽 |
| 弱磁后电流异常 | `Id/Iq` 圆约束、退磁限制、过调制 | 电压幅值、电流幅值和负 `Id` | 关闭弱磁，确认电压限幅后再开启 |

表格只是排查优先级，不是根因判定。每个实验都要有预期波形和停止条件。

## 4. 采样和死区重点

单电阻或低侧采样必须同时审核：

- 开关状态到测量电流的映射和极性；
- 运放压摆率、稳定时间、ADC 采样保持时间；
- 采样窗口是否被死区、窄脉冲或扇区边界占用；
- 移相后比较值是否在需要的计数器边界双更新；
- FOC 计算是否能在下一采样点前完成；
- 实际电压是否包含死区和器件压降，电压重构是否作方向补偿。

课件中的“约 3 us 移相宽度”和“20 kHz 极限约 22 us 计算时间”属于特定硬件/时序下的工程经验，不应复制为通用阈值。应以当前 MCU、PWM 计数方式、运放和 ADC 数据手册以及实测时序为准。

## 5. 高频注入和离散延时

注入幅值越大，位置误差信号通常越明显，但电流、损耗和噪声也增大；幅值太小则信噪比不足。注入频率应避开明显的机械/声学共振和可听频段，不能只看算法分辨率。正弦或脉振注入要补偿 PWM 生效延时造成的相位偏移；方波注入也必须保证采样电流与当前注入电压相匹配。

## 6. 硬件调试安全

带功率级和转动部件的实验必须从低母线、低电流、空载或机械安全状态开始：

- 先被动读取波形和日志，再做停机、复位、寄存器或 GDB 操作；
- 过流、失控加速、异常声音、温升、母线异常或采样饱和立即停机；
- 不因“只是调参数”跳过硬件保护和用户确认；
- 不用单次成功替代重复性、热态、带载和方向变化验证。

在本项目中需要 MCU 证据时使用 `aitrace`，并遵守其被动优先和侵入分级。
