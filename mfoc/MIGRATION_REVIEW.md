# 首批计算基建迁移审核

2026-10-19，`dev-focv2`。先审核旧公式，再迁移；旧 `foc/` 及现有目标构建不改。

## 迁移前发现

| 项目 | 旧实现 | 结论及本批处理 |
| --- | --- | --- |
| BAM32 回绕 | uint32 自然加法回绕 | 保留，不换成弧度和 fmod 热路径 |
| sin/cos 共享 | Core 已算一次后供 Park/逆 Park 使用 | 保留，不重复计算 |
| FIXED sin/cos | 浮点表、浮点插值、转回 Q15 | 改用 Q15 表及 32 位整数插值；误差界和目标符号检查单独验证 |
| sin/cos 查表索引 | sin/cos 分别解码象限和分数 | 共享一次相位分解，四分之一波镜像；输出精度单独验收 |
| 恰好半圈角差 | 存在对 INT32_MIN 取负的路径 | 改成不溢出的有符号映射，统一 -0.5 圈约定 |
| FIXED atan2 | 未归一化，小向量过早被右移量化，大向量可能溢出 | 同一整数 CORDIC 迭代前归一化并精确处理轴线；旧代码实测 atan2(1,1)=0.129821777 圈，放大后为 0.125 圈 |
| FLOAT 角度输入 | 先转 int32，超范围/非有限值转换有风险 | 常用 [-1,1] 保留短路径；其他有限输入用 fmodf，非有限转零 |
| BAM32 转 float | 接近一圈时可能舍入为 1.0 | 把显示边界限制在最大的小于 1 的 float；热路径仍用 BAM32 |
| FLOAT 到 FIXED | NaN 最终可能进入整数转换 | 定义 NaN 转零、无穷饱和；checked 除法仍显式报错 |
| checked 除法失败输出 | FLOAT 溢出时先写入 Inf，FIXED 则不提交 | 新库统一失败不修改输出，错误码保持显式 |
| Clarke 公因式 | 两次乘法后相减 | `(V-W)/sqrt(3)` 可少一次乘法，但 FIXED 舍入和饱和顺序改变；本批保留原次序 |
| Park/逆 Park | 四次乘法后相加减 | 合并宽累加可能减少舍入，但会改变定点结果；本批保留 |
| SVPWM | min/max 共模注入 | 已无需扇区 atan2/sin，保留；不另带同公式的“第三谐波”别名 |
| 调制利用率文档 | SPWM 50% 与 SVPWM 86.7% 的注释口径混杂 | 新头文件明确以母线为基值：SPWM 线性矢量幅值 0.5，SVPWM 为 1/sqrt(3)，后者提高约 15.47% |
| 调制输入验证 | 非有限输入可能带着 OK 返回 | 新库显式拒绝非有限值和分量超出 [-1,1] 的输入；范围内公式与旧实现保持一致 |
| FLOAT `/3`、Q15 `/32768` | 常数除法 | 应查目标代码，不能见 `/` 就断言调用慢除法；本批保留 |
| FIXED sqrt | 32 位逐位平方根，必要时输入按 4 缩放 | 无浮点依赖，保留既有精度；改 64 位精确开方不一定更快 |
| 旧分拆 gain | 整数部分+小数部分，给旧 PID 使用 | 暂不迁入纯标量层，随新 PID 设计再审核 |

不使用 fast-math、近似倒数、无条件 FMA 或删除错误检查换取表面性能。它们可能改变异常处理、舍入和数值边界，须作为独立改动。

## 公式和标度核对

采用幅值不变的平衡三相约定，Clarke 为 `alpha=U`、`beta=(V-W)/sqrt(3)`。这不是包含零序的通用三相变换；不同时迁移会隐藏量化差异的两电流捷径。

Park：`d=alpha*cos(theta)+beta*sin(theta)`、`q=beta*cos(theta)-alpha*sin(theta)`。逆 Park：`alpha=d*cos(theta)-q*sin(theta)`、`beta=d*sin(theta)+q*cos(theta)`。同拍共享 sin/cos，保持原符号、逐乘积缩放和饱和次序。

SVPWM 先计算 `a=alpha`、`b=-alpha/2+sqrt(3)*beta/2`、`c=-alpha/2-sqrt(3)*beta/2`，共模量 `offset=-(max(a,b,c)+min(a,b,c))/2`，再以 `duty=phase+offset+0.5` 居中并裁到 [0,1]。输入是相对母线的调制度，不是任意电压基值下的电压。

电压重建使用 `u_alpha=(2*du-dv-dw)*bus/3`、`u_beta=(dv-dw)*bus/sqrt(3)`，其中 `bus=Vdc/Vbase`。共模占空比不产生 alpha-beta 电压；计算不包含死区和器件压降，也不自动确定采样拍关系。

FIXED 的一般乘法保留 64 位中间积及向零缩放，PU 乘法保留输入限幅和就近舍入。二者不能为了统一名称而互换。`(V-W)*k` 与 `V*k-W*k`、先合并宽乘积再缩放等改写，虽然实数代数等价，但不是逐位等价的迁移；先保留，后续另做误差和目标周期对照。

## 已执行验证

- `mfoc/tests/run_tests.ps1`：FLOAT/FIXED LUT、FLOAT libm、FLOAT/FIXED 外部直接绑定，共五组独立主机测试通过。外部绑定使用测试替身，不代表硬件 CORDIC 已接好。
- 每组扫描 100,000 个相位。LUT 对 double libm 的最大观测绝对误差：FLOAT 约 1.22322e-6，FIXED 约 3.03067e-5；这是测试集合结果，不代替全实数域的形式化误差证明。
- 两种数值后端分别与旧库做 20,000 组对照。迁出的变换、调制、重建、一般/PU 乘法和平方根在各自旧公式有效范围内保持相同结果；FLOAT LUT 一致，FIXED LUT 新旧差异最多一个 Q15 计数（1/32768）。
- 检查恰好半圈、跨圈、极大有限角度、NaN/Inf、除零/溢出且失败不改输出、INT32_MIN/MAX、零/小/大向量 atan2、随机 FIXED 向量、平方根和坐标往返。
- `mfoc/tests/check_arm.ps1`：全体源文件通过 Cortex-M0 FIXED/soft-float 和 Cortex-M4 FLOAT/hard-float 目标编译。M0 FIXED 查表对象未引用外部或软浮点辅助函数；旧查表对象引用浮点加减乘、整数/浮点转换及 `foc_from_float`。
- 同一 M0/O2 编译下，查表对象 `.text`（含只读表）旧 2568 B、新 2208 B；data/bss 都为零。该比较不含旧实现被链接进来的软浮点辅助函数，也不代表整个库或固件的体积差值。
- 旧代码的小向量例子在新库误差断言内通过。整数 CORDIC 沿用 14 次迭代和原角度常数，归一化采用固定次数的位宽判断，避免因小输入增加逐位循环。

## 审核边界

本批是新计算层，未接入控制程序。名称与单位文档、测试、已标明的边界修正供用户审核，不代表完整 FOC v2 架构已定型。代码体积、无浮点热路径和静态运算减少不能折算成实机 ISR 节省多少微秒；后续硬件绑定后再测。

## 公共类型与有限值检查复核

`mfoc_result_t` 与 `mfoc_scalar_t` 统一放入 `mfoc_types.h`，该头文件仅依赖标准整数和布尔类型；`mfoc_numeric.h` 包含公共类型，负责运算和数值常量，避免相互包含或为一个枚举增加头文件。

当前 LLVM/ARM `-O2` 下，对 FLOAT 有限值封装单独编译：读取 float 位表示、清符号位、与 `0x7f800000` 比较，没有 `bl` 或分类库函数调用。独立测试入口共 7 条 Thumb 指令（含返回），不能直接换算成 7 个 CPU 周期；实际内联检查可能融合分支。FIXED 返回常量 true，调用点的无效分支可由优化器消除。因此保留标准 `isfinite`，不手写 union/type-punning 来重复编译器已经完成的工作。

| 位置 | 判断 |
| --- | --- |
| checked 除法输入和结果 | 都保留：有限输入仍可能因分母太小而溢出，结果检查不重复 |
| float 圈数转 BAM32 | 保留：避免 NaN/Inf 到整数转换 |
| atan2 外部向量输入 | 保留；软件 atan2 的有限有界结果复用私有编码函数，去掉再次进入公共转换器的重复校验 |
| SVPWM/SPWM 公共入口 | 保留输入有限/范围校验，错误码仍区分非有限与越界；私有相电压和裁剪函数不重复校验 |
| 电压重建的占空比 | 用有序闭区间判断同时拒绝越界与 NaN/Inf，不另做三次 finite 检查；母线仍须有限且正 |
| 电压重建的输出 | 删除 finite 和 FIXED 载体溢出复查：有效占空比保证两个母线缩放系数的绝对值都小于 1，最大合法母线也不会使结果溢出 |
| 标量加减乘、Clarke/Park、LUT、sqrt | 不逐变量追加有限检查；其输入前提由接口说明，实际输入边界负责验证 |

新增测试覆盖每个占空比分量的 NaN/Inf/越界、非法母线、FLOAT/FIXED 最大母线与 8 组占空比角点，保持非法输入返回码和零输出行为。五组后端、两组旧库对照、M0/M4 目标编译及所有公共头独立包含均通过。

同一 Cortex-M4/FLOAT/LUT/`-O2 -ffp-contract=off` 下，角度对象 text 从 708 B 到 656 B，调制对象从 1092 B 到 1012 B。这是代码体积证据，不是周期或 ISR 耗时数据。包含有限值安全契约的编译须保留 NaN/Inf 语义，不能启用假定输入永远有限的优化后继续声称检查有效。
