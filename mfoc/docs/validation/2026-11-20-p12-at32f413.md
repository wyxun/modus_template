# P12 AT-MOTOR-EVB V1.1 接入

第二块功率板为 AT-MOTOR-EVB V1.1，核心板为 AT32F413RCT7。软件沿用仓库的 `TARGET_CHIP=at32f413`。接线以随板原理图 `AT-MOTOR-EVB-V1.1_SCH.pdf` 和雅特力 V2.1.4 工程的 V1.x 硬件配置为依据。厂商例程路径为 `motor_evb_2v0/at32f413/pmsm_foc_hall_sensor/`，其中 `inc/mc_hwio_v1.h`、`src/mc_hwio.c` 对应本板引脚和外设。

| 信号 | 板上接线与适配 |
| --- | --- |
| 三相 PWM 和 Break | TMR1 高侧 PA8/9/10，有效高、空闲低。低侧 PB13/14/15，有效低、空闲高。PB12 Break 有效低，硬件撤销 MOE，禁用自动恢复。 |
| 三相电流 | ADC1 预注入 PA0/1/2。2 mΩ 分流、16.5 倍放大，标称 33 mV/A。输出相电流使用 `offset - raw`，门极关闭时采八帧求零偏。 |
| 母线 | PA7，经 19.39 倍分压。启动前由前台触发采样，等完整 DMA 帧并检查 9–15 V 窗口。初次调试使用稳压 12 V 和 2804 电机参数。 |
| Hall | J1 对应 PB4/5/0。霍尔线序、电角零点及跳线状态需要对应实物和电机核对。可选构建从应用提供的实测扇区表读取配置。 |

默认软件构建为 FIXED + Flux，Hall 是可选的 POSITION 构建。TMR1 按 200 MHz 定时器时钟和中心对齐 20 kHz 配置。TMR1 CH4 在载波峰值附近触发三路 ADC；AT32 目标的调制上限为 0.35 V/Vdc，为直接三分流读取留出低侧导通窗口。使用原有 Hardware Break，停机清 MOE 时保留 ADC 触发。启动先装载三相比较值，再允许输出。MFOC 算法沿用公共库。

## 复跑

在仓库根目录执行构建或主机 Port 回归。

```powershell
.\make.bat TARGET_CHIP=at32f413 BUILD=debug-rel MFOC_NUMERIC=fixed
.\mfoc\tests\scripts\run_at32f413_port_tests.ps1
```

Hall 构建加 `AT32F413_MFOC_HALL=1 AT32F413_HALL_CONFIG_DIR=<目录>`。该目录的 `mfoc_at32_hall_config.h` 定义 `MFOC_AT32_HALL_SECTORS`，内容为按电角正方向排列的六组 `{三位码, {BAM32 入口角}}`。Hall H1、H2、H3 分别对应三位码的第 0、1、2 位。主机测试的合成扇区表用于软件回归，硬件构建用实测表。

### BLDC5562D048 的 24 V Hall 构建

规格书给出 4 极，电角换算使用 2 对极。24 V 台架使用 24 V 母线基值，
板级启动允许窗口为 18–30 V。电流基值 3.5 A 用于相电流峰值归一化，
现有应用的 dq 电流参考上限 0.14 PU 对应 0.49 A。电角频率基值 400 Hz
按 48 V 标称空载 12000 rpm 换算，24 V 实际转速待测。

```powershell
.\make.bat TARGET_CHIP=at32f413 BUILD=debug-rel MFOC_NUMERIC=fixed `
    AT32F413_BUS_VOLTAGE=24 AT32F413_MFOC_HALL=1 `
    "AT32F413_HALL_CONFIG_DIR=你的实测表目录" `
    MFOC_MOTOR_CONFIG=mfoc/config/motors/motor_bldc5562d048_hall_24v.h
```

Hall 接线完成后，以实测六步表和电角零点作为上板配置。Rs、Ld、Lq、
磁链和惯量暂缺实测值，本配置只开放 Hall，编译时拒绝无感观测器、
HFI 或辨识。电流环和速度环沿用应用现有初始 PU 增益。24 V 下同一
电流误差对应的 PI 电压校正量是 12 V 时的两倍，增益需实机核定。
合成扇区表仅供软件测试。

24 V Hall 的 FLOAT、FIXED 发布和调试构建均通过。Port 主机回归覆盖
窗口相邻的 ADC 码以及 12 V、48 V 拒绝起桥。两种调试 ELF 都用合成
Hall 码回放了初始化、开桥、带电流命令的 ADC 中断和停机。与 12 V
Hall 发布构建对比，ADC 中断、Motor Step、Port 电流读取、位置读取和
PWM 写入的指令及重定位一致。两块板的默认 FLOAT、FIXED 发布 HEX
与改动前逐字节一致。实际接线和电角零点待上板核对。

可给上面的调试构建加 `BUILD_DIR=build/at32-hall24`，从仓库根目录
回放该目录的 ELF。用 `float` 构建时将脚本的 `fixed` 参数改为 `float`。
脚本使用真实应用 Init、Motor 和 ADC 向量，并用仿真寄存器提供 24 V、
Hall 和 Break 输入，验证输出不可自动恢复及显式重启。

```powershell
uv run --with unicorn --with pyelftools python -B mfoc/tests/port/at32f413_hall_control_replay.py fixed build/at32-hall24/template.elf
```

## 软件验证

AT32F413 使用 Embedded LLVM 19.1.5，四个 release 配置和 FIXED Flux debug-rel 完成链接。下表单位为字节。Hall 构建使用临时的合成扇区表。

| 构建 | text | data | bss |
| --- | ---: | ---: | ---: |
| Release FIXED Flux | 19,920 | 1,788 | 1,176 |
| Release FLOAT Flux | 17,876 | 1,788 | 1,168 |
| Release FIXED Hall | 19,480 | 1,792 | 1,232 |
| Release FLOAT Hall | 18,924 | 1,792 | 1,224 |
| Debug-rel FIXED Flux | 41,280 | 1,960 | 13,472 |

主机测试覆盖两种后端、Hall 开关、掉到备用时钟、校零超时、相电流正负、母线拒绝、Break 拒绝启动及停机。Hall 回放还验证位序、边沿速度、扇区验证和无效码拒绝启动。ARM 寄存器模拟用调试 ELF 核对 PWM 极性、ARR/CH4、输出禁止时的 ADC 触发配置、比较值先于 MOE、按需母线 DMA 读数和空闲态 ADC IRQ 确认。FIXED 电流换算与 PWM 提交未发现软浮点调用。G431 的 FLOAT 和 FIXED release 固件分别与 P11 基线逐字节一致。

## 静态 MDI 迁移

AT32F413 的资源绑定在 `peripheral/at32f413/mdi/instance.h`。MFOC Port 使用 `phase_current`、`bridge`、`adc_bus_voltage`、`raw_tick` 和可选的 `hall_inputs`。ADC 向量在进入控制前检查 PCCE，在完成后确认。Port 只读取已经交付的三相帧。校零时由前台拥有完成标志。PWM 普通提交只写三相预装载寄存器，启动时由 MDI 在开 MOE 前触发更新。PB12 Break 仍为硬件关断，只有明确启动且故障条件解除时才清除锁存并恢复输出。

板级结构参照 `peripheral/template/mdi`。`backend.h` 提供 GPIO、UART、ADC 和 PWM 的寄存器操作及静态绑定宏，`instance.h` 声明具体资源和引脚、通道、定时器及存储的映射。`state.c` 存放 UART 和 DMA 缓冲，`service.c` 初始化队列后通过后端开启 UART 中断。规则 ADC 沿用上电和开 PWM 前的按需采样，因此不注册周期采集服务。控制频率由 AT32F413 目标配置同时传给 TMR1 和 MFOC，默认 20 kHz。Hall 引脚在板级启动时配置，MFOC Port 负责读取和解释霍尔扇区。

串口 Shell 使用 `board_stream`，USART1 仍为 PB6/PB7、115200 8N1。RX 字节进入队列后可读取，原 5 ms 串口分帧计时已移出 SysTick。消息分帧由上层协议负责。串口构建和收发、溢出、末字节发送完成回放通过。USART1 中断单独接收由 77 降至 48 条指令，收发并发由 114 降至 75 条，软件栈峰值分别由 32 B 变为 40 B。

Cortex-M4 对链接后的 release ELF 逐拍模拟。相电流 125 组三相输入、PWM 216 组三相占空比及各后端 64 拍 Flux 控制均与迁移前逐位一致。

| 路径 | FLOAT 指令数 | FIXED 指令数 | FLOAT 软件栈峰值 | FIXED 软件栈峰值 |
| --- | ---: | ---: | ---: | ---: |
| 读取与换算三相电流 | 52 → 34 | 65 → 52 | 32 → 16 B | 40 → 32 B |
| 三相 PWM 提交 | 32 → 24 | 26 → 21 | 8 → 0 B | 8 → 0 B |
| Flux 采样中断整拍 | 686–690 → 660–664 | 1393–1435 → 1375–1417 | 248 B | 288 B |

指令数含被调用的函数，软件栈峰值不含硬件中断压栈。ADC 向量入口的对象机器码一致。`-Os`、`-O2` 下三相采样和 PWM 提交直接访问寄存器，无中间调用。四个 release 构建和 FIXED Flux debug-rel 均通过，常规 RAM 占用与迁移前相同。G431 FLOAT、FIXED release 固件仍逐字节一致。板级电气时序和功率输出待实测。

## 板上待测

- 先确认六路 PWM 的门极关闭电平、有效极性和死区，验证 PB12 拉低时硬件关闭输出及解除后的显式重新启动行为。
- 测 TMR1 CH4、ADC 三相完成帧、三次 CCR 写入和 preload 生效的实际位置。确认 20 kHz 每周期只处理一帧，最大调制下三相采样窗覆盖有效低侧导通。三路 compare 必须赶在同一次更新之前写完。
- 核对 Flux 的电压模型与真实区间。峰值附近采样，若 preload 在两次采样之间的谷值生效，电流区间会跨前后两条 duty。稳态时影响小，命令变化时需根据实测结果评估。P12 的位置闭环可先用已标定的 Hall，使首轮闭环验证独立于该模型。
- 记录第一块实测电机、工作母线、相序和反馈方向。霍尔方案须确认扇区表、TMR3 边沿到读码的最大延迟及前台队列余量能覆盖测试速度；使用 Flux 时另验启动和观测器接管。

## 24 V Hall 最终实机验收

待 Hall 接线完成后，用 24 V 电源、BLDC5562D048 和 FIXED Hall 按以下
顺序取证。构建与烧录依据实测扇区表，采集工具为 SWD 和串口。PWM
装载和采样窗采用片内时标与电流响应间接确认。

| 顺序 | 操作 | 记录与通过条件 |
| --- | --- | --- |
| 1 | 保持关桥，手转轴读取 Hall | 记录 H1/H2/H3 正反向六步码序，没有 0/7 或跳扇区。按实际相序建立电角表并核对电角零点；记录母线与三相电流零偏 |
| 2 | 首次受限开桥，先从低速电流与速度闭环验证 | 记录正反向、转速、相电流、实际调制、负载、启停次数和 Hall 队列状态。正常运行无漏帧、异常 Hall 码、溢出或误故障。确认限幅后正常恢复 |
| 3 | 实测采样与 PWM 间隔 | 记录 TMR1 CH4 触发、ADC PCCE 就绪、末次 CCR 写入、预装载转移和完整退出。单拍电压脉冲对照后续电流增量，确认 preload 时间归属及是否需要改变区间模型。低速闭环采集整圈三相 KCL，逐档记最高调制、各相占空比和高占空比区间残差 |
| 4 | 验证最重路径与 Break | 从实测窗口核验帧就绪到末写不超过 80%，控制 ISR 在下一完整帧前退出。覆盖速度 PI 和限幅。校验 PB12 Break 后硬件关桥，故障源有效时拒绝启动，解除后保留关闭直到显式重启 |
| 5 | 收尾 | 通过 SWD 回读门极关闭状态，记录最终构建 SHA-256、配置、时钟、工具链、原始日志和最终支持范围 |

开桥前明确台架的电流和转速边界。0.49 A 是应用电流命令上限，
母线电源限流值及硬件 Break 阈值分别记录。验证范围与结果回填到
[支持矩阵](../support-matrix.md)。
