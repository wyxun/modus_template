# P12 板级软件整改评审稿

基线 `bc6affe`。本稿登记 Hall 捕获、运行期母线和 Break 重启策略，供 P10 时序设计并行评审。下面的采样周期、过期阈值和资源用量均属候选，需要软件对照或实测才能成为板级验收值。

## AT32F413 Hall 捕获

已按评审意见接通 TMR3 硬件捕获。J1 的 H1/H2/H3 分别走 PB4/PB5/PB0，沿用官方 V2.1.4 V1 接线和 `TMR3_GMUX_0010`。三路异或的每个跳变经 C1INC 产生一个脉冲，CH1 从 STI 捕获其上升沿。计数器自由运行，PSC=199，ARR=65535，仅 CH1 捕获产生中断。首次采集和每次显式启动先取当前扇区，检查交接期间的捕获标志，成功后才开捕获 IRQ。[板级配置](../../../peripheral/at32f413/port_sys.c) · [F413 参考手册的通道输入和 Hall XOR 路径](https://www.arterychip.com/download/RM/RM_AT32F413_EN_V2.04.pdf)

**边沿时刻。** TMR3 时钟为 2 × APB1 = 200 MHz，SysTick 也用 200 MHz 内核时钟。每条边沿用 `edge_tick = port_tick - (uint16_t)(count - capture) * 200` 反推；16 位乘 200 在 32 位内可表示。取 Port tick 前后各读一次 CVAL，区间超过 1 µs 时重取一次，再失败则锁存 SAFETY。该方法的计数量化和顺序读取误差小于 2 µs，另计管脚同步、时钟门控及 Port 时基误差。捕获 IRQ 与 SysTick 同为最低抢占优先级 15，ADC 为 1。每条边沿直接用当前 Port 时钟，长时间静止不会积累 TMR3 回绕计数。

**码与时刻配对。** IRQ 先读 C1DT，再单次读 GPIOB 三位码，并核对新捕获与重捕获标志。8 槽队列按先后顺序送给前台，前台一次最多处理进入时已有的 8 项。队满、发现重捕获、读码时出现下一边沿或连续两次读时钟超窗，立即锁存 SAFETY、停捕获 IRQ；前台和控制拍取位置均返回 SAFETY，消费者输出保持原值。调试器可读 `s_edges.overruns` 查看上述捕获失败的累计次数。非法码/跳扇区同样要求重新采集。停机后的显式启动丢弃历史队列，从当前物理扇区重新获取。[Port 实现](../../../peripheral/at32f413/mfoc/mfoc_port.c)

**回放结果。** FLOAT、FIXED 均覆盖六条正转、六条反转、一次消费多条、前台排队/队满、8 位队列索引回绕、16 位捕获回绕、静止 25 s 超过 Port 低 32 位回绕、100 ms 超时边界、重捕获、读码中二次捕获、启动交接和故障后重启。在 2 ms 的单扇区间隔、4–30 µs 不等的 IRQ 延迟下，测得速度与 ±83.333 电 Hz 的差小于 0.00005 PU（基值 400 Hz）。[寄存器用例](../../tests/port/at32f413/port_test.c)

| Cortex-M4 release 机器码回放 | 执行指令 / 次 | 函数及被调栈峰 | PRIMASK 连续置位指令 |
| --- | ---: | ---: | ---: |
| 普通 Hall 边沿 | 104 | 64 B | 30 |
| SysTick 溢出待服务 | 125 | 64 B | 51 |
| 时钟取样遇 ADC 抢占重取且 SysTick 挂起 | 192 | 64 B | 51 |
| 硬件重捕获拒收 | 51 | 40 B | 0 |

以上两种后端数值相同，模拟器执行实际 ELF 中的 IRQ、perfc 时钟函数和厂商驱动。指令数不含模拟注入的高优先级 ISR 和异常进出硬件压栈。PRIMASK 区间来自已有 `get_system_ticks()`，与原先前台轮询发现边沿时的同一时钟调用相同。额外重取会再次短暂屏蔽 ADC，实际入口抖动待板测。Hall 开启后，对比旧轮询固件，text 增 FLOAT 960 B / FIXED 964 B，data 持平，bss 各增 80 B。采样 ISR 中的 `mfoc_port_position` 沿用一次状态检查，函数体从 56 B 降到 54 B，有效拍函数本体执行 19 → 18 条指令，局部栈仍为 24 B；计算角度的 Hall Step 保持原算法。Hall 关闭的 FLOAT/FIXED release 可烧录 HEX 均与原固件逐字节相同。[ARM 回放脚本](../../tests/port/at32f413/hall_capture_replay.py)

**上板准入。** 必须实测边沿到读码小于最短扇区，边沿到时基取样小于 65.536 ms。孤立边沿延迟满一圈时，16 位差值无法自证延迟。相邻 SysTick 溢出须在下次溢出前获服务，实测最长前台停顿内应少于队列可容纳的 8 个新边沿。200 电 Hz、均匀六扇区仅供估算，单扇区约 833 µs、8 个扇区约 6.67 ms，以实测转速、扇区宽度和 ISR 抢占为准。回放还发现当前宿主 SysTick 移植 `get_system_timer_top()` 返回 LOAD+1，perfc 对每次溢出再加 1。1 ms 周期多计 1 个 5 ns tick，长期约 +5 ppm。Hall 每条边沿重新锚定 Port 时钟，捕获延迟跨毫秒时把这个误差计入。当前软件回放不能验收物理抗噪、输入传播延迟和最高转速。

## 两块板的运行期母线

| 板 | 当前数据源 | 候选采样与发布 |
| --- | --- | --- |
| G431 | 规则 ADC 默认 100 Hz 发起 DMA，每块 10 组采样；前台计算均值并发布已有序号 | 复用已发布均值和对应采集时间。DMA 出错或均值尚未发布时保留诊断状态。 |
| AT32F413 | 普通组 4 通道 DMA，当前由上电及开桥前按需软件触发 | 候选沿用 100 Hz，由前台到期发起普通组转换。一次只允许一帧在途。前台在下次启动前检查 FDT/传输错误并读取 Vbus，成功才发布新序号。与启动用新帧检查共享单一事务所有者。控制电流仍由 TMR1 CH4 触发。 |

两板以母线采集起点计龄。前台用 `mfoc_core_PrepareBus` 生成与 `SetBus` 逐位一致的系数，在双缓冲槽内放入采集时刻、到期帧号、状态和这一组系数，再发布序号。运行期只有采样 ISR 通过 `mfoc_core_ApplyBus` 更新 Core。限幅、调制和本拍 `output.bus` 共用这组值，PWM 提交后的模型电压使用配对的母线。[前后台交接](../../../class/mfoc_board_bus.c) · [Core 接口](../../core/include/mfoc_core.h)

启动须取得有效新帧，AT32 保留既有 9–15 V 开桥联锁及超时拒启。运行中重复序号继续使用有效期内旧值；普通在途状态不刷新年龄。有效期候选为三个采集周期（100 Hz 时 30 ms），待按电源动态和保护需求评审。过期、DMA 硬故障或超出该板确认的运行范围时，走采样故障和关桥路径，不以 1 PU 兜底。对运行范围单列板级判据，AT32 启动范围和 G431 ADC 换算上界均有各自用途。即使前台停止调度，控制侧也须检测发布停滞。IDLE 可在前台写 Core，启停边界序列化；运行期生产者不得覆盖 ISR 已选中的快照。

成本评审分四种输入：无新帧、有效新帧、过期/失败、停机启动。比较两板 FLOAT/FIXED 的写 PWM 前和整拍周期、局部栈、RAM/Flash，特别列出 FIXED 倒数和限幅重算。主机回放母线阶跃、重复/回绕序号、帧更新打断换算、前台失联、坏帧及启动交接，检查新旧系数成组可见、出错保留旧系数并执行规定停机。实际差额确认后接入生产控制路径。

### 本轮母线实现

`MFOC_RUNTIME_BUS=1` 开启候选。G431 按 DMA 原始槽保存采集起点，发布均值时转交同一时间戳。AT32 前台按 100 Hz 启动四通道 DMA，启动联锁与轮询共用同一事务，运行范围为 9–15 V。G431 沿用原 Port 的正值及换算范围检查，工作电压保护值待板级验收。[G431 采集](../../../peripheral/stm32g431/mdi/service.c) · [AT32 采集](../../../peripheral/at32f413/mfoc/mfoc_port.c)

正常运行时，前台先读控制帧号，再取绝对时间。从 30 ms 减去采集至此已经用掉的时间，将剩余时间按 `MFOC_MOTOR_RUN_FREQ_HZ` 折成排他的截止帧号。20 kHz 时完整窗口为 600 拍，16 kHz 时为 480 拍；处在两次采样之间的发布可保守提前一拍到期。若取时期间被采样中断抢占，使用较早的帧号，避免延长有效期。首次开桥和每次重启都在开桥前验一次绝对年龄，首个运行 IRQ 再按当时的真实年龄建立帧龄。其后新帧和无新帧都按控制帧号到期，停止发布、硬件报错或样本已过期由原采样故障路径关桥。该换算以运行时控制中断按配置频率逐帧到达为前提；漏帧和长期停中断由 P10 的独立时序验收覆盖。[两板碰撞回放](2026-11-22-p12-runtime-bus-replay.md)

### AT32 普通组与电流组抢占预算

F413 ADC1 当前配置在 12.5 MHz，普通组 4 个 rank，电流组 3 个 rank，均为 1.5 周期采样加 12.5 周期转换。每 rank 为 1.12 µs。普通组被电流触发打断，电流转换后继续；在电流组已开始时触发普通组则延至电流组完成。故一次最不利重叠中，普通组须给电流组让出最多 **3.36 µs 转换时间**。若计入外部注入触发响应上界 **3 / 12.5 MHz + 1 / 100 MHz = 0.25 µs**，可为该占用预留 **3.61 µs**。保守地再为普通单 rank 重采留 1.12 µs 时，四 rank 合计转换排程为 4.48 + 3.61 + 1.12 = **9.21 µs**，另计普通启动、DMA 完成和前台调度。四个普通 rank 不构成电流触发前的串行阻塞。电流侧单列触发到首次采样的手册上界 0.25 µs，三路完成预计在触发后 3.61 µs 内，不含 IRQ 响应。100 Hz 普通帧开始时刻与 PWM 相位可碰撞，板测须分普通组空闲/正在采样/正在转换比较 CH4 到电流完成的范围和抖动。DMA 状态机回放不能证明硅片上的最大延迟。[AT32F413 RM §19.4.1](https://www.arterychip.com/download/RM/RM_AT32F413_EN_V2.04.pdf) · [AT32F413 数据手册表 44](https://www.arterychip.com/download/DS/DS_AT32F413_V2.02_EN.pdf)

候选保持注入组配置固定。芯片勘误 ES0006 §1.2.2 要求普通 CCE 与注入 PCCE 同时发生时连续两次清除 PCCE，否则下一拍可能收不到完成标志。启用运行期普通扫描时，控制 IRQ 收尾和首次开 IRQ 都复用双写 ACK；它的额外写入计入 AT32 候选成本。[雅特力 F413 勘误](https://www.arterytek.com/download/Errata/ES0006_AT32F413_Errata_Sheet_V2.0.15_EN.pdf)

## Break 恢复契约

两块板保留各自的历史锁存策略，公共头及 Port 移植指南已明确显式启动的板级差异。共同要求为物理故障有效时拒绝开桥，普通 duty 写入和 Stop 均不确认故障，清锁存期间保持相输出关闭，恢复时检查故障是否复发。

| `mfoc_port_pwm_start()` 看到的条件 | G431 | AT32F413 |
| --- | --- | --- |
| 物理源仍有效 | COMP1/2/4 接 TIM1 BKIN，拒绝打开相输出，返回 SAFETY | PB12 低有效，拒绝开 MOE，返回 SAFETY |
| 物理源解除、历史锁存仍在 | Start 检查 BIF 或软件锁存并返回 SAFETY。需在相输出关闭时由板级显式确认，再启动。Motor 软件 ClearFault 操作独立。 | 显式 Start 完成新母线和时钟等前置检查、关桥后，可清已解除的历史锁存。Enable 再核对故障，成功才恢复输出。 |
| 清后再次触发 | 硬件 Break 仍有效，重新锁存、拒绝开桥或关桥 | 硬件 Break 仍有效，重新置位、拒绝开桥或关桥 |

G431 开启主 Break，Break IRQ 先锁存软件状态再确认 BIF，硬件不依赖 IRQ 响应才撤销 MOE。AT32 禁止自动恢复，现有测试对“输入解除、BRK_FLAG 尚存、显式 Start 成功”已有断言。本次 FLOAT/FIXED 寄存器回放覆盖持续故障、解除留锁存、清除后复发、重复 Stop、普通 duty 写入保留锁存和门关闭。[G431 Break 配置](../../../peripheral/stm32g431/haltim1.c) · [G431 门控](../../../peripheral/stm32g431/mdi/pwm.h) · [AT32 启动](../../../peripheral/at32f413/mfoc/mfoc_port.c) · [AT32 已有断言](../../tests/port/at32f413/port_test.c)
