# P10 G431 候选 B · 旁路裁剪和单文件优化

所有台架对照均以 B 顶部更新为时序。每组只变更一个因素。170 MHz、20 kHz、debug-rel 端点探针，运行期母线和波形关闭，保留浮点分步舍入 `-ffp-contract=off`。三组 `-Os` 基线的 HEX 与原冻结包一致。Flux/SMO 使用 `motor sensorless 0.4 0.05`，HFI 使用 `motor hfi start`。

写前列为最迟写入拍的 `W−I`。IRQ 至尾标取最迟尾标拍上的 `Esoft−I`，这包含 PWM 后的工作，异常返回部分在尾标之外。频繁路径和重拍命中数均保留在原始 RTT 记录。软件栈用同一 ELF、匹配输入和最低 SP 回放，范围为 `Motor.Step` 的实际调用链。硬件异常压栈、浮点懒入栈及系统嵌套栈峰值不在此数据中。

## 旁路位置外推裁剪

候选只在非 POSITION 主反馈时跳过 IRQ 里的旁路外推，保留编码器前台初始化、I2C 轮询和中断负载。两份候选与基线的应用对象相同，唯一替换对象是 `mfoc_feedback.o`，差异段只有 `mfoc_feedback_Step` 代码及对应重定位。

| 工况 | 写前周期，基线 → 裁剪 | IRQ 至尾标周期，基线 → 裁剪 | Flash | 路径软件栈 |
| --- | ---: | ---: | ---: | ---: |
| FLOAT Flux | 3424 → 2934（−2.88 µs） | 5296 → 4810（−2.86 µs） | 51,760 → 51,512 B | 320 → 232 B |
| FIXED HFI 第八拍 | 6654 → 5878（−4.56 µs） | 7735 → 6972（−4.49 µs） | 52,628 → 52,348 B | 384 → 352 B |

两份候选均无静态 RAM 变化；530 拍匹配输入中，三相 CCR、模型电压、dq、限幅、速度 PI、Flux/HFI 状态及故障均逐位一致。FIXED HFI 基线最迟写入为 T+7432 tick，裁剪后为 T+6658，距推算更新点尚有 1852 tick（10.89 µs）。20% 初筛未达标拍由 1030/10000 变为 0/10000，尾标晚于推算的下一触发点由 2 变为 0。两组都在获取期超时，尚无锁定或叠加速度 PI 的实机结论。

此次测的是关闭波形的发布裁剪候选。打开角度波形时继续走原同拍位置读取。若后续要将它移到 PWM 写入后，须保留原读取时标和当拍的有效/失效/未读语义，再单独对照；直接晚读会改变外推角和过期边界。

## 单文件 `-O2`

移除没有命中任何 MFOC 对象的 `motor.o` 规则。用 `MFOC_O2_OBJECT=mfoc_hfi` 选择一个真实对象进入 `-O2`，默认仍按工程优化级别。对象名纳入构建签名以保证切换重编。通过主 Makefile 重建的 HFI 候选 HEX 与独立对照逐字节相同。每行都与未裁剪旁路的 `-Os` 基线比较。

| 工况 / 单个 `-O2` 对象 | 写前周期 | IRQ 至尾标周期 | Flash 差额 | 逐拍数值差 |
| --- | ---: | ---: | ---: | ---: |
| FIXED HFI `-Os` 基线 | 6654 | 7735 | 基准 52,628 B | 基准 |
| `mfoc_feedback` | 6444（−210） | 7538（−197） | +24 B | 0 bit |
| `mfoc_hfi` | 6654（0） | 7735（0） | 0 B | 0 bit |
| `mfoc_core` | 6805（+151） | 7895（+160） | +440 B | 0 bit |
| `mfoc_motor` | 6730（+76） | 7805（+70） | +364 B | 0 bit |
| `mfoc_pi` | 6626（−28） | 7707（−28） | +16 B | 0 bit |
| `mfoc_transform` | 6581（−73） | 7666（−69） | +8 B | 0 bit |
| `mfoc_modulation` | 6635（−19） | 7716（−19） | 0 B | 0 bit |
| `mfoc_trig` | 6583（−71） | 7668（−67） | +8 B | 0 bit |
| `mfoc_angle` | 6697（+43） | 7782（+47） | +280 B | 0 bit |
| FLOAT Flux `-Os` 基线 | 3424 | 5296 | 基准 51,760 B | 基准 |
| `mfoc_flux` | 3420（−4） | 5293（−3） | +8 B | 0 bit |
| FLOAT SMO `-Os` 基线 | 4005 | 5907 | 基准 52,952 B | 基准 |
| `mfoc_smo` | 4030（+25） | 5926（+19） | +224 B | 0 bit |

各单文件候选的路径软件栈均持平，FIXED HFI 384 B，FLOAT Flux/SMO 320 B。数值差来自逐拍同输入回放，FIXED HFI 每个候选 130 拍，FLOAT 候选各 195 拍，检查 CCR、重建电压、Core/PI、主观测器状态和故障分支。FLOAT SMO 的测速窗分别命中 6792、6751 拍，两次均完成无感接管，测速窗的最大 T→W 为 4781、4793 tick。

本轮最值得保留作下一轮对照的单文件候选是 `mfoc_feedback`。它的 FIXED HFI 写前约省 1.24 µs，尾标约省 1.16 µs，回放在第八拍及与速度 PI 同拍时也各省 106 条指令；Flash 多 24 B，仍有 900 个获取期重拍未达 20% 初筛，发布配置保持 `-Os`。Motor 与 SMO 的离线指令减少未转化为此次实机峰值收益。其余几十周期的差异缺少一致的回放和实机证据，保留原优化级别。每份 `-O2` 镜像都保留旁路位置读取，因而无法把任一差额与旁路裁剪直接相加。

## 证据与后续边界

16 份实机运行的 RTT、固件哈希、最迟写入及尾标 RAM 快照和 `bench-timing.csv` 位于 `artifacts/p10-g431-20261122-stage2`。每次结束均关桥。FIXED HFI 的 `mfoc_hfi -O2` 停桥轮询有一次拒收，仍取得 16 帧；该运行段无缺帧或双 JEOS 不齐。G431 默认 FLOAT/FIXED release HEX 与基线逐字节一致。

阶段 2.1 和 2.2 的对照已完成。旁路裁剪具备最大的已测收益，保留为候选，生产路径仍使用原代码。后续需拆 HFI 第八拍的宽除法和角度计算，再进入 B 的延迟电压对齐及完整矩阵。获取期端点余量只覆盖本次试验，锁定后 HFI 与速度 PI、限幅、运行期母线同拍，以及实际异常退出到下一完整 ADC 帧的余量仍待最终验收。
