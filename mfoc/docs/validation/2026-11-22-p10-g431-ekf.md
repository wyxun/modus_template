# G431 FLOAT EKF 的 20 kHz 验证

2026-11-22，G431 最终 B，2804 空载，12 V / 0.5 A。保留现有电机模型、启动参数、编码器诊断与保护，角度波形关闭。用 `motor sensorless 0.4 0.05` 自动对齐、开环升速和接管。RTT 不在控制中途读状态。写入以 ADC 触发参考为起点，门槛 6705 tick。退出以低优先级 TIM2 见证实际异常返回的上界，门槛 8436 tick。每 tick 对应 1/170 µs。

## 分段定位

原 `-Os` 第 3 拍进入完整 EKF 更新。预测 693 tick（4.08 µs），α 校正 2784 tick（16.38 µs），β 校正 2732 tick（16.07 µs）。此前的通用 EKF 分段探针测得整段 6678 tick（39.28 µs）。关闭探针仍触发 PWM 写入故障。两次 Joseph 协方差校正是主要开销。

只把 `mfoc_ekf.c` 改用 `-O2`，保留 `-ffp-contract=off`、现有算式和保护。独立的分段固件记录 EKF 峰值 2746 tick（16.15 µs）。分段固件自身的软件尾标超过周期，该固件只用于定位热点。正式时序按端点版测量。

| 端点构建 | 帧数 | 接管 | 速度 PI 帧 | 最大写入，tick | 最大退出上界，tick | 故障 / 退出超时 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 单文件 `-O2` | 123722 | 1 | 2243 | 6035 | 8019 | 0 / 0 |
| 单文件 `-O3` | 122984 | 1 | 2169 | 5974 | 7933 | 0 / 0 |
| `STM32G431_EKF=1` 复测 | 122772 | 1 | 2184 | 6020 | 7997 | 0 / 0 |

`-O2` 写入 35.50 µs，距 20% 余量门槛还有 670 tick（3.94 µs）。退出上界 47.17 µs，距保守退出门槛还有 417 tick（2.45 µs）。同工况 `-O3` 的写入只再省约 0.36 µs，保留 `-O2`。相对原 `-Os` 诊断端点固件，`-O2` 增 280 B Flash，静态数据和 BSS 相同。目标 ELF 普通 EKF 步的软件栈由 384 B 降到 232 B，大角回绕回放由 424 B 降到 272 B。1920 帧逐拍运行的两种优化级别与原版状态和输出逐位一致。独立 6144 帧回放、包含大角回绕的定向验证，以及主机 EKF 测试也通过。

## 构建与验证范围

G431 通过 `STM32G431_EKF=1` 选择 FLOAT EKF 主反馈，保持 20 kHz。仅优化 EKF 源文件，其他后端沿用原来的构建配置。开关默认关闭。改动前后的默认 FLOAT、FIXED release HEX 分别逐字节一致。新开关生成的端点 HEX 与上述已测 `-O2` 端点镜像逐字节一致。FIXED 或同时选择其他探针后端会在 Make 阶段拒绝。

现有 `STM32G431_CONTROL_HZ=10000` 可以构建独立的 10 kHz EKF 镜像，TIM1 和采样周期随配置派生。速度环仍为 1 kHz。真要切换到 10 kHz，需要复核电流 PI 的离散积分系数、EKF 每拍过程噪声与增加的实时时间延迟。这次保持 20 kHz，只在主机验证了 10 kHz 的构建和相关回放。

原始超时见 `artifacts/p10-g431-ekf-20261122-231353/`。本轮分段、端点、退出见证、逐拍回放和停止读回见 `artifacts/p10-g431-ekf-rate-20261122-232231/`。上板复测结束，三相输出关闭，TIM1 ARR 读回 4250。本轮工况覆盖自动启动、接管和速度 PI，角度波形、限幅碰撞及运行期母线更新另需各自时序证据。

## 波形与限幅、速度 PI、母线刷新同拍

保持 20 kHz 电流环。角度波形用 2 kHz 采集，登记 `Enc_mT`、`EKF_mT` 和 `Err_mT`。诊断镜像使用现有第 4 通道载送启动阶段标记。ECU 的 EKF 算术始终使用同一份单文件 `-O2` 机器码。

第一次自动启动未校电角零点，闭环圆均值角差约 −174.85 电度。第二次上电后先执行 `motor align`，待关桥和电角零位校准完成后，在同一次上电执行 `motor sensorless 0.4 0.05`。第二次启动共 12292 个连续波形样本。采集文件开头保留了少量先前校零过程的缓冲数据，按样本索引 3000 起算，不计入自动启动统计。

| 校零后状态 | 波形时间或角差 |
| --- | --- |
| 固定角结束，进入开环 | 1.500 s |
| 开始融合 EKF 角 | 4.0265 s |
| 速度 PI 接手 | 4.0530 s |
| 结束启动，进入常规闭环 | 4.0730 s |
| 融合前后各 25 ms 圆均值角差 | +15.35° / +16.21° |
| 常规闭环前后各 25 ms 圆均值角差 | +14.88° / +16.97° |
| 闭环 +200 ms 后 | 编码器和 EKF 均为 159.84 电 Hz，角差圆均值 +16.17°，去均值 RMS 3.65° |

两次闭环运行均无故障。校零后速度和相位差在接管窗口内保持连续，约 +16° 电角稳态偏差仍需建立独立误差预算。

关掉波形后打开实际运行期母线更新。探针仅在 EKF 完成接管、速度 PI 到期且真实新母线系数成功应用的拍，将当拍 Core 限幅半径暂时减半。每次只改一拍，保持原有电流和桥保护。回放确认探针不改变速度环调度，不制造母线帧。以下写入和退出均以 ADC 触发参考计时。

| 构建与启动 | 有效帧 / 三项同拍 | 整轮 / 三项末次写入，tick | 整轮 / 三项退出见证上界，tick |
| --- | ---: | ---: | ---: |
| 去退出见证，冷启 | 149628 / 10 | 6294 / 6164 | — |
| 有见证，冷启 | 150176 / 12 | 6310 / 6167 | 8398 / 7490 |
| 有见证，冷启复测 | 149562 / 16 | 6268 / 6168 | **8444** / 7491 |
| 有见证，停机后再启 | 149314 / 5 | 6274 / 6166 | 8403 / 7489 |

43 个三项同拍的最迟写入 6168 tick（36.28 µs），距 6705 tick 门槛 537 tick（3.16 µs）。有见证的 33 个三项同拍全部按时，最迟 7491 tick（44.06 µs），距保守退出线 945 tick（5.56 µs）。四轮整轮最迟写入也全部通过，最迟 6310 tick，余量 395 tick（2.32 µs）。

三个有见证的试次总计 449052 帧，全数配对，冷启复测第 4 拍有一次见证晚于 8436 tick 保守线 8 tick（0.047 µs）。该拍仍在下一 ADC 触发参考前 56 tick（0.33 µs），属于固定角启动期，无三项事件。实时性结论为三项同拍通过，启动全阶段保守退出门槛还未全通过。总计 598680 帧，NVIC 核验通过，缺帧、相位异常、ADC 缺帧、缺写及电机故障均为零。所有试次结束均核对三相关闭，最终板上为关闭波形的诊断镜像。

默认 `release` 与 `debug-rel` 使用 `-Os`，`debug` 使用 `-O0`。G431 FLOAT EKF 的 `mfoc_ekf.o` 及 G431 FIXED 的 `mfoc_core.o` 在各自配置中单独使用 `-O2`。同一组独立目标回放显示，EKF 原版 `-Os` 约 3550 指令、384 B 栈，单文件 `-O2` 约 832 指令、232 B 栈。继续用 `-Os` 并定向指示 Clang 展开五个循环，可做到约 819 指令及相同栈，独立 ELF 少 60 B。仅加 `-funroll-loops` 时指令数无改善。保留已经上板验证的单文件 `-O2`，未更改生产控制代码或保护。

两组原始角度波形、校零后图表、四轮端点、退出见证与停止核验在 `artifacts/p10-g431-ekf-wave-collision-20261122-233244/`。碰撞固件和精确触发条件回放在 `build/p10-ekf-collision/`，循环展开回放见 `build/p10-ekf-current/unroll-subset/results.json`。
