# P09 G431 单变量诊断复测

2026-11-22，2804 空载，G431 最终 B，12 V / 0.5 A 限流，P09 诊断统一使用 3.80 Ω。构建都在隔离覆盖目录，保留既有相电流保护、前台超时及带时间戳的原始机械角诊断。先测旋转辨识，再测 HFI 与 Ld/Lq。

## 1. 旋转辨识

现有起步先用 0.04 PU 的 α 轴直压对齐 300 ms，再切入同方向的 d 轴电流 PI 并升速。预保持候选单独测试了切入电流 PI 后额外静止 31 块（49.6 ms）再开始角度升速。反电势阈值沿用块均值的 L1 口径，0.020 PU 相当于 0.24 V。0.015 PU 死区估算是名义量级，实际静止块中曾看到 0.025–0.035 PU 的估算残余。

有效提交最迟写入 5908 tick，最迟软件尾标 6997 tick（FIXED）；各次日志无丢帧、相位错误或 ADC 缺帧。按现有 128 tick 尾声预留筛查，最迟有效拍仍早于下次触发参考。此记录的尾标用于定位 P09 候选耗时，P10 的实际退出证据仍以其独立发布验收为准。每次停止后确认三相关闭。原始固件与日志在 `artifacts/p09-g431-rotation-20261122-122111/`，基准 FIXED 的近 64 块记录另见 `artifacts/p09-g431-encoder-check-20261122-121055/`。

## 2. HFI 转子凸极

FLOAT 同一请求角先做 0、0.04、0.08、0.12 PU 幅值对照，再用现有固定 d 轴电流对齐入口逐角度重复注入。每次对齐、采集和停机分别核对原始机械角、相电流保护及输出状态。20 组完整 HFI 采集均未锁定，均无相电流越限。峰值 0.0567 PU（约 0.199 A），低于 0.12 PU 保护。首次 0.08 PU 对齐请求无回包，三相关闭后同一镜像重试成功。

零注入的一个有效 32 组窗口中，α、β 单组轴向流差 RMS 分别为 0.00980、0.00896 PU；有符号相干平均幅值分别为 0.000066、0.000644 PU。0.04、0.08、0.12 PU 的单组解调通过率从约 64% 提高到约 90% 和 97%–99%。通过率衡量解调门槛，凸极定性使用与实测转子角同步的 2θ 分量。

在稀疏诊断之外，补做连续的 128 组尾窗。拟合前要求 32 组连续、原始角最大跨度 3 个机械计数、同一对齐位置的有效窗口足够接近，并检查施加的两列正交电压。0.12 PU 的八个请求角没有保持为八个均匀相隔的采样角。注入后自由转轴多次漂向相近区域，合用可用早窗与连续尾窗后仍留 100.54° 电角空档。拟合所得疑似 2θ 幅值 0.061、残差 RMS 0.038，角覆盖没有通过。当前只能确认该工况下升幅提高了解调通过率但没有实现锁定。台架记录不足以确定 2804 的物理凸极强度，后续需要固定转轴位置再复测。

原始 RTT、停止读回、逐组 Di/Du、编码器快照和拟合参数在 `artifacts/p09-g431-hfi-saliency-20261122-122901/`。停止读回文件为每轮的 `outputs-disabled.log`，总拟合为 `harmonic-fit-tail.json`。

## 4. 8 对脉冲落地

Motor 的 ELECTRICAL 流程改为每轴 8 对正负脉冲。默认每半波 8 区间，共累计 128 个实际施加区间。B 预装载路径在最后一个脉冲生效时已排入下一拍中性，等待末区间的电流样本再完成。独立单脉冲 `Step`、`Finish`、`InitTiming` 和 `FinishPrepared` 保留原行为与类型，两个前台流程共用求值公式。

G431 用实际落地源码分别跑通 FLOAT 和 FIXED。每轴都记录到 130 个流程帧及一次末区间。实机 FLOAT 测得 1.266 / 1.274 mH，FIXED 测得 1.241 / 1.477 mH。此轮验证实际激励区间及完整结果，FIXED 单次 Ld 低于前一轮 5 次的范围，重复性仍按前一轮的原始样本判断。FIXED 电感帧最迟写入 2606 tick，软件尾标 4237 tick，均低于前一轮 8 对候选的实测峰值。

FLOAT/FIXED 回归覆盖 B 预装载、直写、丢区间、错极性、超流、取消、旧单脉冲及独立 PMSM 回放。普通闭环的 IRQ、Motor、Core、Feedback、SMO、Flux、调制和 Port 的目标指令与重定位逐项一致，旧单脉冲 Step 的机器码也一致。G431 和 AT32F413 的四份默认 release HEX 与改动前逐字节一致。

落地固件、RTT 和停止读回在 `artifacts/p09-g431-ld-land-20261122-224715/`。两轮均确认三相输出关闭。

## 7. 电感定稿与 HFI 台架安排

2026-11-23 确认 Motor 的 Ld/Lq 采用已落地的每轴 8 对正负对称脉冲。方案定稿，落地版本的多轮重复性与绝对误差仍需独立参考和实机数据支持。

G431 + 2804 的 HFI 结果冻结为本工况未锁定、凸极证据不足。该组合停止追加 HFI 试验，后续改用 AT32F413 搭配其他电机验证。2804 的结论只覆盖已记录的测试工况。
