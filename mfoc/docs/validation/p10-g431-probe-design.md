# P10 G431 分段探针与验收设计

设计已原则通过，候选探针与回放记录见文末。设计基线为 `bc6affe`。此稿给出 A、B 两种预装载方案共用的计时点、证据和判据。现有探针在检查 ADC1 帧就绪之后才取入口时间，只接受 CH1–3 关闭预装载，并按变化的比较边沿统计余量。新候选须分别检查预装载、目标 UEV 相位和完整双 ADC 帧；原始首测数据保留其原口径。[三拍时序与相位锁定](2026-11-21-p10-g431-phase-design.md) · [现有探针](../../../target/stm32g431/mfoc_p10_timing.c) · [首测记录](2026-11-20-p10-g431-timing.md)

## 1. 冻结抢占优先级

下表是从现有 G431 启动链核到的设定，也是 A/B 对照的拟冻结值。采用 `NVIC_PRIORITYGROUP_4`（AIRCR.PRIGROUP=3，4 位抢占，0 位子优先级），数值越小优先级越高。**ADC1_2 保持 1，并且是唯一处于最高抢占优先级的已启用常规中断**；0 级在试验配置中保留空闲。源码能确认设置意图，实机回读后才确认当次运行满足条件。[HAL 分组](../../../vendor/cortex-m/stm32g4xx_hal_driver/Src/stm32g4xx_hal.c) · [G431 优先级位数](../../../vendor/cortex-m/cmsis_device_g4/Include/stm32g431xx.h)

| 中断源 | 拟冻结抢占级 | 触发与使用 |
|---|---:|---|
| ADC1_2 | 1 | ADC1 注入组 JEOS 在开桥时使能。ADC2 JEOS 同拍读取。 |
| TIM1_BRK_TIM15 | 2 | 保留硬件 Break 直接关门极，IRQ 锁存软件故障。故障拍独立记录。 |
| DMA1_Channel1 | 2 | 保留常规 ADC 的 TC/TE 和真实 DMA 负载。DMA 的总线竞争仍计入测量。 |
| SysTick | 3 | HAL 初始化期间使用 15，随后板级时钟初始化改为 3。main 调 `perfc_init(true)`，当前 Cortex-M port 保留已占用的 SysTick 设置。 |
| USART2 | 4 | MDI 串口收发。保留发布配置中的中断入口。 |
| I2C1_EV / I2C1_ER | 禁用 | 编码器 I²C1 在前台轮询，无 IRQ 优先级参与此次排序。 |
| FDCAN1_IT0 / IT1 | 禁用 | FDCAN 驱动若初始化会设置为 0；当前 `peripheral_Init` 路径没有启用它。 |
| TIM1_UP_TIM16 / TIM1_CC、其余外设 IRQ | 禁用 | 相位和触发探针优先用硬件输出或捕获，避免额外 TIM1 IRQ 改变抢占关系。 |

核查点为板级、perfc、MDI 全部初始化以后以及开桥使能 JEOS 后。保存目标/固件 ID、AIRCR、所有已使能外部 IRQ 的 ISER/IPR 解码值、SysTick CTRL/SHPR、ADC1/2 IER 和 TIM1 DIER，并与上表比对。检查同级的其他 IRQ 也很重要，它们可能延迟 ADC 进入。异常的优先级、额外开启的向量或分组变化须单列和复测。固定优先级异常 NMI/HardFault、软件临界区屏蔽和总线等待仍可能影响响应；入组时记录故障、PRIMASK/BASEPRI 的使用路径及实际 `trigger → irq_entry` 延迟，入口看到的掩码不能还原此前等待时间。[启动顺序](../../../src/main.c) · [板级时钟与 I²C](../../../peripheral/stm32g431/port_sys.c) · [perfc 初始化实现](../../../modus/src/arch/perfc_port.c) · [ADC 与 DMA](../../../peripheral/stm32g431/haladc.c) · [TIM1 Break](../../../peripheral/stm32g431/haltim1.c) · [USART2](../../../peripheral/stm32g431/mdi/backend.h) · [MDI 启用 DMA](../../../peripheral/stm32g431/mdi/service.c) · [FDCAN 配置](../../../peripheral/stm32g431/halfdcan.c)

## 2. 同拍取点和计时

一次记录对应一个硬件帧号。硬件触发与生效事件采用同一计时参考，校准示波器或捕获定时器与 TIM1 的固定偏移；软件段用 DWT.CYCCNT 作无符号差值，跨周期通过帧号及 TIM1 方向/计数展开。170 MHz 下 170 个内核周期为 1 µs。DWT 须在测量前确认已启用且递增，和硬件捕获时钟做同步。帧序号取自触发/UEV 的独立硬件计数或捕获记录，ISR 调用次数本身不能揭示遗漏的整帧。记录原始 tick、相位、参考时钟和换算值。取点如下。

| 事件或区间 | 放置方法 | 判读 |
|---|---|---|
| `T` 与 `T → I` | 通过已核实对应 TIM1_CH4 注入触发边沿的硬件通道或同步定时器捕获标记 `T`。在 ADC1_2 向量**首条可观测指令**取 `I`，在运行态判断和读 READY 前。 | 含触发同步、ADC 转换、NVIC 等待及异常进入；标记晚于向量入口的固定指令须计入不确定度。 |
| 完整帧 `J` | `J=max(JEOS1, JEOS2)`，对同一触发的两条注入序列分别核对 JEOS。ADC1 触发 IRQ；当前 READY 只查 ADC1。把首次检查双 JEOS 的时间另记为 `J_seen`。 | IRQ 标记只能界定 ADC1 的完成；只有同时读到同帧双 JEOS 的 `J_seen` 才能作完整帧 J 的上界。ADC2 未就绪或无法辨认帧号时记录一致性异常，不能把旧 JDR 值计作成功控制拍。[绑定](../../../peripheral/stm32g431/mdi/instance.h) |
| 调度与 `port_current` | 分别取 Motor Step 入口及 `mfoc_port_current` 前后时间，涵盖 JDR 读取、码值换算和帧确认。Clarke 和参考选择另计余项。 | 保留失败/无帧路径标记。 |
| `feedback` | 取 Feedback 总入口/返回时间，并分别包围旁路 `mfoc_port_position` 和各实际调用的主观测器、旁路观测器。 | 记录主反馈、有效性、启动阶段、HFI 注入许可。总时间已有各子段，汇总只计一次；纯对齐或直压辨识可跳过该段。 |
| `speed PI` / `core` | 仅在速度 PI 实际执行时围住该调用，再围住 `mfoc_core_Step`。 | 记录分频到期与圆形限幅分支，可与观测器重算同拍命中。 |
| `port_pwm` 与 `W` | 在提交入口取点，三相 CCR 最后一次 volatile 写之后执行测量用 DSB，再取 DWT 时间作为保守 `W⁺`。记录三相请求值和返回结果；用硬件边沿/捕获确认总线完成界能覆盖外设接受写入到装载所需的时间。 | `W⁺` 含总线写完成和时间戳开销。预装载开启时，软件读回 CCR 的数值不能证明三相已经在引脚上生效。 |
| `U` | 同时捕获 TIM1 自然 UEV 硬件标记或已验证的同步从定时器标记、三相实际边沿。用已知的相邻不同占空比，核对三相首次表现新比较值的周期。 | 分清同拍目标 UEV 和后续 UEV；预定截止点属于提交目标拍，晚写不能把截止顺延。 |
| `post-PWM → E` | 记录 `W⁺` 后的模型电压重建、状态保存、分频提交、帧确认、诊断至 IRQ 最后软件标记。用同步异常跟踪，或已标定的尾声、异常返回及测量误差上界，给出真正退出的保守 `E⁺`。 | 后一个 IRQ 的入口本身不证明前一 IRQ 及时退出。采样标记必须覆盖尾声及异常返回，出现尾链时按本 ADC 异常结束计。 |

ADC 帧完成可能没有可直接引出的硬件信号。可在关闭门极的校准工况中，以同一实际触发为参考，清除前帧 JEOS，定时连续读取双 JEOS，记录最后一次未齐和首次齐全的时间界，覆盖常规 ADC 空闲与并发转换。报告读取耗时、跨时钟同步及正反方向。如果这组界不能证明覆盖带载运行的实际帧，用每拍确实早于完成的触发时刻作 `J⁻`，或用经验证的硬件事件/延迟界收紧；仅有停止状态的样本分布不能替代运行最坏界。对物理采样有效性的验证还要看各相采样孔径及其周围低侧导通时间。[ADC 注入序列](../../../peripheral/stm32g431/haladc.c) · [STM32G4 RM0440](https://www.st.com/resource/en/reference_manual/rm0440-stm32g4-series-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)

统计采用小缓冲或固定窗口，保存每类命中数、各段最大值及最小余量的**同一拍**完整记录。每帧给出总历时、各互斥分段和未归属差值，避免将不同帧的最大值相加。CCR 写前仅记原始时间，汇总优先放在停机后；若在 ISR 内写后汇总，其成本仍进入退出验收。方案 A/B 各保留轻量端点测量和分段诊断两种对照，固定优化级、频率、波形开关、负载与命令。用连续打点、GPIO 对 DWT 及端点/分段成对回放记录扰动。用端点构建核对 20% 余量，分段构建解释热点；另核对生产选项下硬件边沿和处理完成标记，记录外推范围。每组记录至少注明编译选项、哈希、探针成本、DWT 回绕处理和覆盖的实际工况。[IRQ 入口与退出](../../port/modus/mfoc_motor_irq.c) · [Motor 调度](../../motor/src/mfoc_motor.c) · [Feedback 调度](../../motor/src/mfoc_feedback.c)

## 3. 逐拍双判据

**V 相示波器取证。** ADC2 的 Rank 1 读 W，Rank 2 读 V。若实际 CC4 触发在顶部前 10 个 TIM1 tick，且忽略触发跨时钟延迟，Rank 2 的完整转换包络为顶部后 **1.729–3.518 µs**，下降段 CNT 约为 **3956–3652**。42.5 MHz 下每次采样保持 6.5 周期，后续逐次逼近 12.5 周期。4 次真实采样孔径相对顶部依次为 1.729–1.882、2.176–2.329、2.624–2.776、3.071–3.224 µs。记录实际 CC4 触发方向，再校正四个区间的公共偏移。按同一拍记录 V 相低侧栅极、分流/放大器输出、顶部参考和相应占空比，检查死区、开关瞬态与模拟稳定时间后四个孔径都处在可用窗内。覆盖最大批准调制比和 V 相最窄导通扇区。板上把区间左、右各自最小余量写入记录，寄存器回放仅验证排列与标号。[ADC 序列配置](../../../peripheral/stm32g431/haladc.c)

每个成功的运行帧 `k` 应同时满足以下条件。相同 duty 帧也参与写入时限统计；寄存器到物理输出的映射另用可辨认命令验证。

1. `5 × (W[k] − J[k]) ≤ 4 × (U[k] − J[k])`，其中 `U[k]` 为该命令预定的自然装载事件，取最迟能安全完成三相预装载的截止点，扣除已确认的硬件建立时间和观测误差。
2. `E[k] < J[k+1]`，且每次触发对应一帧、每个有效运行帧对应预期提交。统计消耗同一帧两次、缺帧/新帧未处理、ADC2 未就绪、定时器相位改变、标记溢出和非预期故障。

有观测区间时，取最迟写入 `W⁺`、最早允许截止 `U⁻`、最早完整帧 `J⁻` 和最迟异常退出 `E⁺`。同一拍保守通过条件为 `5W⁺ − 4U⁻ − J⁻ ≤ 0` 和 `E⁺ < J⁻[k+1]`。反向界如能证明超限则记失败；证据区间跨越边界则记待测。报告两项各自的最大比例或最小余量、帧号和原始证据。应走故障保护且不写新 duty 的路径单独验证预期失败、停桥、帧确认和退出时间。

## 2026-11-22 已实施的 A/B 探针及软件回放

A 在谷底装载，B 在下一个顶部装载。TIM2 的 CCR1 在硬件里锁存每次 TIM1 自然 UEV 的时间，TIM2 的 CNT 给入口、双 JEOS 首次检查、DSB 后末次 CCR 写和中断尾部打点。由最近的捕获反推本拍触发 T 及该命令预定的 U，迟写仍与原 U 比较。跨越未处理的整个 PWM 周期会改变连续两次 T 的差，进入 `gap` 计数。同一拍的两次读数发生跨 UEV 竞争时计为相位无效。每次开桥后单独建立连续性基准。软件没有记录停机期间的缺帧。[计算与边界](../../../target/stm32g431/mfoc_p10_deadline.h) · [候选探针](../../../target/stm32g431/mfoc_p10_candidate.c)

| RTT 命令 | 读数及适用条件 |
|---|---|
| `p10 frame` | 停桥、三路主/互补输出关闭且两个 ADC 都禁用 JEOS IRQ。丢弃第一对黏滞 JEOS 标志，轮询 16 个新帧，每帧保存最后一次未齐与第一次双 ADC 都齐的读数界。仅应答 JEOS，保留其他标志。报告相对 T 的最小下界、最大上界、最宽单帧区间及拒收数。输出仅适用于当次停桥校准。 |
| `p10 clear` | 电机停止时清除统计。下一次开桥后重新读取 NVIC 及 ADC/TIM1 中断使能寄存器。 |
| `p10` | 停机后读组命中数及最大 T→W、T→尾标、最大 W→尾标、完整帧缺失、漏写、首次异常、相位/连续性错误。最坏写入拍和最坏尾标拍各保留原始 T/I/Jseen/W/U/Esoft、三相 CCR、双 ADC 标志、返回码及分组掩码。绝对时间以十六进制给出，作 32 位无符号差，历时以十进制 tick 给出。 |

端点版只在实际重计算分支写标签。分段版另对电流读取、整个 Feedback、物理位置读取、各观测器、速度 PI、辨识、Core、Port PWM 的实际调用前后读 DWT。未执行的段为 0。Feedback 总时长含其子段，PWM 调用时长包括 DSB 后的探针，W 是其内部时间。统计上一拍的工作放在下一拍写 PWM 后，计入后一拍尾部耗时，停机读取时补齐最后一拍。另行编入运行期母线更新时，`bus_new`、`bus_speed`、`bus_smo_window`、`bus_hfi_8`、`bus_limit`、`bus_speed_heavy`、`bus_speed_heavy_limit` 汇报本拍新系数已采用时的峰值。0 命中表示本次没有覆盖该组合。[分段绑定](../../../target/stm32g431/mfoc_trace_binding.h)

按 170 MHz、ARR=4250、CCR4=4240 计算，A 的 T→U 为 4260 tick，B 为 8510 tick。初筛把 J 的下界取在 T，留 20% 时 T→W 分别以 3408、6808 tick 为界。完整验收须再扣除 TIM1→TIM2 捕获偏移、CCR 装载建立时间，以及尾标后的指令和异常返回时间。最大调制比下同时观察 V 相低侧门极与相电流，在顶部后约 1.73–3.52 µs 内核对 ADC2 Rank 2 的四次采样孔径；双 JEOS 的时间只能定位帧完成。示波器还需记录三相首次采用新占空比的周期。当前硬件余量、尾声上界和采样孔径均待取证。
