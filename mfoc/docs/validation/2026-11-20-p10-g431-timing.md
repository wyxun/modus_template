## 测量口径

TIM1 以 170 MHz 计数，中心对齐 PWM 的 ARR 为 4250。CH4 的 CCR4 为 4240。一个完整周期为 8500 tick，即 50 µs。现场核对 CH4 的触发边沿及下降计数方向，记录所用的波形或可以确认相位的等效证据。

CH1–3 的比较寄存器直接生效。本拍需要改变的比较值，以老值和新值中最大的那个作为最早可能需要更新的下降计数边沿。设 `m` 为三相中所有变更通道的老值和新值的最大值，以从零向上为相位 0，则下降计数边沿相位为 `2 × ARR − m`。提前按 `CCR4` 标记最早可能触发相位，使软件量得的触发至写入时间包含 ADC 转换、IRQ 响应和探针开销。同值写入仍纳入计算耗时统计，边沿余量统计只使用变化的通道。

默认 0.55 PU 最大调制时，理论最大占空比约 97.63%，相应 CCR 约 4149。按出现在峰值前 10 tick 的最早触发计算，到该下降计数边沿只有约 111 tick（0.65 µs）。源码配置的 ADC 标称转换链约为 608 个 TIM1 tick（3.58 µs），实际还受触发同步影响。这是极值工况下需要核对低侧采样窗口、实际边沿和截止定义的原因。

`max_irq` 从 IRQ 确认帧就绪后的计时点量到最后一次 CCR 写入之后，包含探针开销。`max_trigger` 按最早触发相位到最后写入之后统计，可在确认触发相位后用作 ADC 完成至写入耗时的保守上界，精确 JEOS 时刻需要额外硬件证据。所有时间读数为 170 MHz tick，除以 170 得 µs。PWM 和定时器行为见 RM0440 的 TIM1 输出比较和 ADC 注入触发章节。[STM32G4 RM0440](https://www.st.com/resource/en/reference_manual/rm0440-stm32g4-series-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)

## 第一次上台架

1. 使用 G431 和已核对过的电机、电源、探针和负载条件，确认板在停机状态。先装载固件包里的 `float-flux`，连接同一组 ELF 所对应的 RTT。以下两个命令分别执行烧录和连接，现场确认后再运行。把 `$build` 替换为实际的相对路径。

   ```powershell
   $build = 'artifacts/p10-g431-实际包目录/float-flux'
   .\make.bat TARGET_CHIP=stm32g431 "BUILD_DIR=$build" download
   .\make.bat TARGET_CHIP=stm32g431 "BUILD_DIR=$build" -o "$build/template.elf" rtt
   ```

2. 停机时用 RTT Shell 执行 `p10`，保存识别行并确认 `hz`、`arr` 和 `ccr4`。从台架上已确认的探测点核对门极停机状态。
3. 每轮停机时执行 `p10 clear`，再由操作者用同一台架已验证的指令和工作范围运行。先做低负载普通拍，结合示波器核对 PWM 极性和边沿。CH4 或 ADC 非引出信号的实际相位须通过可用的板级硬件证据核对。随后在已批准的范围内记录启动、稳态和变化工况。用既有电机命令启动 SMO/Flux 交接，HFI 可用 `motor hfi start` 和 `motor hfi status`。限幅工况使用已有的台架限值，按日志的命中数确认是否覆盖。
4. 每轮由操作者执行 `motor stop`，停稳后执行 `p10` 并保留完整输出。后续按相同条件换另一数值版本和反馈配置。记录固件 SHA-256、板卡和电机、母线电压、转向和负载、有效工况时间及实测波形。

## 读数和验收

| 字段 | 判读 |
| --- | --- |
| `ready`、`invalid`、`gap`、`no_write`、`adc2_pending`、`faults` | 先核对采样帧、间隔、提交和故障情况。意外缺帧或故障应查明来源再取该工况结果。 |
| `all`、`limited`、`smo_window`、`hfi_group` | 总样本、限幅样本、SMO 测速窗、HFI 载波组。目标类别 `writes=0` 表示本轮没有覆盖。 |
| `writes`、`changed`、`late`、`reserve_fail` | 记录提交、变化和余量异常。保守余量要求至少保留最早触发与对应边沿之间的 20%。 |
| `max_irq`、`max_trigger`、`min_slack` | 保存每组最大耗时和最小剩余时间。只在 `changed` 大于零时读取 `min_slack`，负余量表示保守统计已跨过对应边沿。 |
| `p10 worst` | 最小余量对应的单拍。保存入口计数和方向、对应 CCR、可用窗口以及两种耗时，用于同示波器波形核对。 |

板上覆盖后，以实际“采样完成至适用 PWM 边沿”的可用窗口核对至少 20% 余量。软件用更早的触发相位进行保守筛查，范围、实际边沿和未覆盖工况留在各轮记录中。六组固件覆盖观测配置和限幅准备，P10 的辨识及剩余板上最坏路径仍按总计划验证。

烧录 `p10-g431-20261120-225638-bfee12e4/float-flux` 并通过 Flash 校验。使用 AITrace 运行 `motor sensorless 0.4 0.05`，两轮都执行 `motor stop`，回读 Motor 为 IDLE。首轮在运行中读到启动状态 NONE、速度环模式和 Flux 有效，估算电频率为 0.394 PU。复跑期间只在启停前后下发 RTT 命令，记录仍覆盖启动和运行。
