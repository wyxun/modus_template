# P10 G431 B 转正与电压区间回放

## 发布路径

- 非 POSITION 主反馈只在角度波形需要物理位置时读编码器。波形复用 Feedback 同一控制拍读取的角度和有效状态。前台传感器更新照常运行。
- FIXED HFI 使用乘法比较检查凸极阈值。内建 CORDIC 使用共同移位后的两坐标，保持外部 `atan2` 的 Q15 输入约定。默认优化级别为 `-Os`。[阶段 2.3 台架证据](2026-11-22-p10-g431-hfi-axis.md)
- G431 默认启用 TIM1 CH1–3 预装载，冷启动在原 PRIMASK 保护下紧邻写入 `CEN` 和 `RCR=1`。TIM2 捕获两个自然顶部 UEV，并核对相位和周期。停机保留计数器，再开桥前应先确认中性预装载值经过新的合格 UEV。故障时桥保持关闭。
- 运行中 Port 核对两 ADC 的帧完成标志、UEV 帧序与写入窗口，三相写入后再核对相位和门控。错帧、末写越过更新点或 Break 触发后，Motor 关桥并丢弃在途电压历史。检查随控制中断执行，丢帧间隔在下一次收到采样时检测。

## 电压与激励归属

| 首次启动后的采样拍 | 顶部 UEV 生效 | 本拍算法消费 | 本拍提交 |
| --- | --- | --- | --- |
| `0` | 初始中性保持 | 无完整区间 | `d[0]` |
| `1` | `d[0]` | 初始中性 | `d[1]` |
| `2` | `d[1]` | `u[0]` | `d[2]` |
| `3` | `d[2]` | `u[1]` | `d[3]` |

每次 PWM 提交成功时，用最终 duty 和该命令配对的母线快照重建电压。Flux、SMO、HFI 和辨识在第 `k` 拍收到 `[k-1,k)` 的 `u[k-2]`。主 Flux 和速度 PI 继续在本拍参与控制。

HFI 将载波相位随发出的电压经过相同的两拍路径，首个中性区间只建立电流基线。首组有效载波从第 `0` 拍命令的对应区间开始，到第 `9` 拍电流到达时收齐。可选极性脉冲按实际施加区间累计。

Ld/Lq 在首个实际脉冲装载时记录电流基线。若相应项目在 `k` 写第一条脉冲命令，`k+1` 取基线，`k+2` 到 `k+9` 累计八个区间，`k+8` 预写中性，最后一段脉冲在 `k+9` 结束。Rs 的稳定窗和统计窗仅使用相应档位实际施加后的样本。

## 软件证据与实机边界

- 正反阶跃、母线切换、故障/停机清历史、SMO/Flux 无感接管均有 FLOAT 与 FIXED 回放。HFI 回放覆盖两种角度方向、首组载波、重启、缺样及可选极性脉冲，并通过实际 Motor/Feedback/Core 核对有感注入和 HFI 获取到闭环的控制语义。
- FLOAT 和 FIXED 均通过延迟功率级模型的 Rs、Ld/Lq、Flux、转动惯量辨识。专项校验不同母线电压下 Ld/Lq 的八个完整区间，以及缺样、错相、电压符号和范围错误。
- G431 与 AT32F413 的 FLOAT/FIXED release 可构建。AT32F413 两份默认 HEX 与 P12 母线关闭的基线逐字节一致。
- G431 的实际 Arm ELF 回放覆盖冷启动锁相、恢复 PRIMASK、停机重启、TIM2 回绕、双 ADC 帧不齐或跳拍、写前超时、写入中经过 UEV，以及写入中触发 Break。运行期母线启用时也覆盖无帧、过期拒绝开桥和新鲜帧允许开桥。[G431 回放用例](../../tests/port/g431_p10_phase_replay.py)
- 实机待验包含最终 B 配置的 2804 HFI 锁定、较高调制区 KCL，以及 FLOAT/FIXED 的写前 20% 余量与整拍退出矩阵。现有单拍脉冲和低调制 KCL 证据取自 B 对照固件。[已测电学范围](2026-11-22-p10-g431-electrical.md)

以下是阶段 3 新增的时序和相位处理开销。Arm 指令由 G431 `-Os` 的 ELF 回放计数。Port 使用稳定采样和中性写入，HFI 使用成功提取 d 轴的第八拍，表中为各自的回放软件栈。

| 回放路径 | FLOAT 指令 | FIXED 指令 | FLOAT 栈 | FIXED 栈 |
| --- | ---: | ---: | ---: | ---: |
| 稳定读帧与校验 | 45 → 77 | 61 → 89 | 16 → 16 B | 24 → 32 B |
| PWM 提交与校验 | 57 → 83 | 47 → 73 | 24 → 24 B | 24 → 24 B |
| HFI 第八拍，含相位对齐 | 339 → 352 | 320 → 334 | 80 → 80 B | 88 → 88 B |

开桥后首个有效采样在稳定读帧的基础上再用 6 条指令。G431 写入检查前完成占空比换算和比较值准备。反汇编中，从读取 TIM2 到三个连续 CCR 写入后的 `DSB` 共 10 条指令，128 个定时器 tick 的写入预留仍需实机核对。

G431 端点 ELF 回放覆盖 FLOAT/FIXED Flux 普通、速度 PI 和限幅，SMO 普通、测速窗和速度 PI 同拍，HFI 第八拍和速度 PI 同拍，以及 Rs。第八拍和速度 PI 同拍时，从 Motor Step 到写完 CCR3 为 FLOAT 1077 条、FIXED 1570 条，完整 Step 分别为 1171 条和 1690 条，回放软件栈为 248 B 和 264 B。

G431 默认 release 的 `.text` 相对阶段 2 增加 644 B（FLOAT）和 640 B（FIXED），两者 `.bss` 均增加 48 B，其中 Motor 电压历史为 8 B。运行期母线默认关闭。开启母线后的 G431 最重回放路径中，普通拍、消费新帧和启动首帧分别多 36、54 和 109 条指令，两种数值后端一致，回放栈峰值持平。该数据用于选择下一轮实机碰撞用例。
