# P10 G431 最终 B 台架

2026-11-22，在 2804 空载台架上使用 12 V 电源、0.5 A 限流，20 kHz 电流环，`-Os`。烧录前匹配 CMSIS-DAP 序列号和 G431 芯片 ID，烧录后校验。运行使用 AITrace RTT，停机后核对三相输出门并通过 SWD 读取匹配 ELF 的 RAM 快照。时间与采样窗取证使用片内时标和电学响应。

## HFI 实机锁定

按 FLOAT、FIXED 先后执行 `motor hfi start`。两种固件均运行到第 10,001 拍（约 0.5 s）后进入 HFI 超时保护，`hfi_lock=0`、`hfi_track=0`。前 10,000 拍均成功写入，`gap`、`phase_invalid`、`adc_incomplete` 均为 0。启动后首次解调对应第 0 拍命令的第八个实际施加区间。

| 路径 | 第八拍通过轴提取 / 总组数 | 两列 ΔI 模长中位数，PU | 两列 ΔU 模长中位数，PU | 有效轴角 RMS，电角 | 有效轴角 P95，电角 |
| --- | ---: | ---: | ---: | ---: | ---: |
| FLOAT | 793 / 1249 | 0.01591 / 0.01681 | 0.08567 / 0.08559 | 49.38° | 86.46° |
| FIXED | 736 / 1249 | 0.01511 / 0.01584 | 0.08512 / 0.08541 | 46.88° | 84.85° |

每种数值后端的幅值及角度统计使用 185 组同组双列样本，前 32 组连续保存，其后每八组选一组。轴角以 180° 为周期计算相对圆均值的距离。幅值最低的总响应约 0.0099 PU，仍高于 0.002 PU 门槛。FLOAT 和 FIXED 的后段凸极指标中位数约 0.73 和 0.83，门槛为 0.04。采样中只有 FLOAT 一组因指标低于 0.04 被拒绝。两者分别有 69 和 75 组因矩阵条件异常被拒绝。

本台架上的直接限制是**轴角估计持续跳动**。前 32 组中相邻且有效的组相距 0.4 ms，轴角跳变中位数为 FLOAT 46.6°、FIXED 62.8°。数据不支持把失败归因到注入不足或 0.04 凸极门槛过高。该指标来自板上差分矩阵，受模型电压、采样与噪声影响，不能单独量出 2804 的固有凸极率。锁定后的跟踪及速度 PI 同拍未发生。采集固件与计时端点分开，关闭采集时发布 HEX 保持逐字节一致。[双列解码](../../tests/port/g431_p10_hfi_capture.py)

## 高占空比 KCL

最终 B 的 FLOAT Flux 在 160 电 Hz 的启动对照中，接管后未完成速度稳定确认，反馈保护关桥。改用 FLOAT SMO，以 `motor sensorless 0.4 0.06` 启动并确认闭环，然后用 `motor speed` 提高目标。KCL 采集在 0.12 PU 相电流保护下录 512 个连续 ADC 帧并自动关桥。V 相采样位于顶部之后，按当拍已装载的 `d[k-1]` 归档。三相电流均由各自 ADC 采样。

| 目标 | 帧 / 分箱 | 最大调制 | 最大 V 相占空比 | 全圈 KCL 峰值 / RMS，PU | 高 V 分箱峰值 / RMS，PU |
| --- | ---: | ---: | ---: | ---: | ---: |
| 180 电 Hz | 512 / 32 | 0.3791 | 82.64% | 0.06303 / 0.02893 | 0.04202 / 0.02703 |
| 200 电 Hz | 19 / 7 | 0.3832（局部） | 51.27%（局部） | 采集因速度保护终止 | 全圈待测 |

180 电 Hz 档最大相电流为 0.05882 PU，约 0.206 A。高 V 按每箱最大占空比距全圈峰值不超过 0.4 个百分点选出两个分箱，共 25 帧。全圈残差最大处的 V 占空比是 57.60%，高 V 分箱的残差幅值和 RMS 均低于全圈统计。本轮间接证据覆盖至 V 相 82.64%，未在该档复现高 V 分箱特有的残差尖峰。200 电 Hz 档观察速度超过 0.52 PU 安全阈值后自动关闭输出，该档不纳入全圈判断。[KCL 快照解码](../../tests/port/g431_p10_kcl.py)

## B 端点时序

`T` 是和 TIM2 自然顶部捕获对齐的 ADC 触发参考点，`W` 在最后一次 CCR 写入和屏障之后打点，`Esoft` 是软件尾标。20% 写入筛查把完整帧就绪的下界保守提前到 `T`，并从 8510 tick 窗口扣除 128 tick 的写入保护预留，故要求 `W−T ≤ 6705 tick`（39.44 µs）。退出筛查给软件尾标后的指令和异常返回预留 128 tick，检查 `Esoft−T+128 < 8500 tick`，下一触发早于下一帧就绪。尾声预算来自固件反汇编边界，实际异常返回未直接打点，因此将退出结果记作带预算的筛查。[判据与时标](p10-g431-probe-design.md)

| 运行路径 | FLOAT `T→W` / `T→Esoft`，µs | FIXED `T→W` / `T→Esoft`，µs |
| --- | ---: | ---: |
| Flux 启动、接管、稳态 | 22.18 / 33.29 | 32.52 / 42.89 |
| SMO 启动、接管、测速窗 | 26.10 / 36.64 | 34.24 / 44.01 |
| HFI 获取期 | 27.14 / 33.56 | 31.66 / 38.67 |
| SMO 启用运行期母线 | 26.52 / 37.91 | 34.99 / 45.19 |
| HFI 获取期启用运行期母线 | 27.80 / 34.89 | 32.32 / 40.64 |

十组端点均有 `nvic_ok=1`，`gap=0`、`phase_invalid=0`、`adc_incomplete=0`，写入与尾标初筛无超限。HFI 四组均发生一次预期的获取超时关桥，统计单列该故障拍。在上述组中最小 20% 写入余量为 4.45 µs，计入尾声预算后的退出余量为 4.05 µs，均出现在 FIXED SMO 母线组。此次记录没有 Core 矢量限幅分支命中，也没有锁定后的 HFI 重拍。

另用诊断命令仅在前台对齐速度 PI 和 SMO 测速窗的相位，稳定运行后出现 4302 个 FLOAT 和 4307 个 FIXED 同拍拍。叠加同拍新母线系数后分别命中 21 和 15 拍，`T→W` 最大为 25.17、35.28 µs，`T→Esoft` 最大为 31.35、41.76 µs。两轮均未出现意外故障。FIXED HFI 母线组同时命中 8 次获取期第八拍及母线更新。FLOAT HFI 的该组合未命中。对齐测试含所有拍的最坏写入为 6023 tick，最慢尾标为 7760 tick，余量分别为 4.01 µs 和 3.60 µs。关掉阶段 3 台架采集与分频对齐开关后，两份 G431 发布 HEX 均与集成基线逐字节一致。

FLOAT Flux 完成连续 20 次启停（1 次冷启、19 次保留 CEN 的热重启），累计 541,201 拍。每次前台启动握手计数递增，顶部捕获间隔维持 8500 tick。另做了 FIXED 冷启和 FLOAT Flux 持续运行，后者累计 625,821 拍（约 31.3 s），正式无感稳态 515,670 拍。上述记录中双 JEOS、帧序和相位检查均未误报，`IO/SAFETY` 或其他故障计数为 0。

## 辨识首次实机结果

| 操作 | FLOAT | FIXED |
| --- | --- | --- |
| Rs | 完成，4.3427 Ω | 完成，4.1587 Ω |
| 电气参数 | Rs 低档稳定性拒绝，未进入 Ld/Lq | 完成，Rs 4.0390 Ω、Ld 1.0736 mH、Lq 1.3002 mH |
| 磁链 | 升速阶段估计电角速度保护 | 升速阶段估计电角速度保护 |
| 惯量 | 升速阶段估计电角速度保护 | 升速阶段估计电角速度保护 |

FLOAT 首次电气辨识的低档前半窗和全窗平均电流相差 0.001736 PU，高于 0.0015 PU 的稳定性门槛。FIXED 电气辨识的 Ld、Lq 各经过 10 个流程采样拍，包含激励发出、基线及八个实际采样区间。四次旋转辨识均在估算电角速度越过 200 rad/s 的保护条件后关桥，尚无真实转速或磁链、惯量的测值。所有有效提交拍中，`T→W` 最大 31.69 µs、`T→Esoft` 最大 37.97 µs。四个 ISR 保护拍均跳过写入，最慢软件尾标为 26.16 µs。两种数值后端分别用匹配的 ELF 读取结束状态与测量值，数据可作 P00/P09 台架参考。当前 Rs 输出比 2804 模型的 2.55 Ω 更高，仍需独立参照核对精度。Ld/Lq 本轮是自由转轴下的台架结果，锁轴条件未验证。

复测中，FLOAT 独立 Rs 一次成功、一次稳定性失败，电气辨识复测完成，给出 Rs 3.9778 Ω、Ld 0.9720 mH、Lq 1.6355 mH。FIXED 独立 Rs 两次为 4.1587、4.0390 Ω。FIXED 电气辨识两次都完成，但 Ld 为 1.0736、0.7690 mH，Lq 为 1.3002、4.5921 mH，重复性未通过本轮核查。另一次 FLOAT Rs 在高档中途主动取消，结果回到 `IDLE`，三相关闭，无故障且无可发布结果。

## 验收状态与原始记录

P10 继续开放。实机已触发的分支均通过带预算的时序筛查。Core 矢量限幅与其重拍组合未命中，磁链和惯量尚未进入测量窗，电感重复性及实际异常退出上界还需要证据。HFI 在本台 2804 上两种后端均未锁定，锁定后相关项无数据。

原始 AITrace RTT、已校验固件、停机快照及解码结果保存在 `artifacts/p10-g431-final-b-20261122-103528/`。一次 USB/SWD 中断及一次编码器 SDA 被拉低在物理重连、重新上电后恢复。被中断的烧录和未开启采集的尝试未纳入结果。最后 SWD 读到 `TIM1_CCER=0x00001000`、`TIM1_CR1=0x00000131`，三相输出关闭，计数器仍运行。
