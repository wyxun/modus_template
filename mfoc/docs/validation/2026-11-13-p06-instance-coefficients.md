# P06 · HFI 与辨识的采样频率、基值和计算量

本页记录 P06 当时的实现与比较。四种无编码器辨识的最终采样路径、编译期时基和软件验收见 [P09 记录](2026-11-19-p09-identification.md)。

本次对照使用当前工作区的算法和临时候选。默认控制频率 `fs = 20,000 Hz`，电频率基值 `fb = 400 Hz`，一拍 50 µs。Hz 表示电周每秒，只有公式需要角频率时才使用 `ωb = 2πfb`。当前生产实现用编译期常量折叠下表中的比值和样本数。改为实例配置的收益是允许同一构建里的实例使用不同基值或节拍；热路径的成本来自读取系数、常数运算的代码生成变化及其所在分支。[频率配置](../configuration.md#board-settings) · [2804 电机配置](../../port/projects/g431_2804/motor_2804.h) · [基值公式](../../motor/include/mfoc_motor_config_internal.h)

## 谁提供配置

- Motor 已接收电流基值、母线电压基值、电频率基值和极对数。参考 profile 为 3.5 A、12 V、400 电 Hz、7 极对。电流和电压由 Port 转成 PU；HFI 和辨识消费 `I/Ibase` 和前区间的 `V/Vbase`。Rs 直接激励命令用 `V/Vdc`，不能拿激励命令代替前区间电压。叶算法无需再按安培或伏特换算。[Motor 配置](../../motor/include/mfoc_motor.h) · [辨识输入与输出](../../identification/include/mfoc_identification_algorithms.h)
- 当前 Motor 仅向 Port、OpenLoop 和若干观测器传递实例电速度基值。HFI 启用时，实例基值必须与编译常量相等。控制频率分散在几个子配置，`openloop.sample_hz = 0` 还表示关闭强拖。若采用实例配置，控制 ISR 的实际调用频率应由 Motor 初始化入口显式提供一次，独立叶的调用者提供同一物理量。硬件 ADC/PWM 仍要按实际节拍接线。[Motor 初始化](../../motor/src/mfoc_motor.c) · [G431 应用配置](../../../class/mfoc_app.c)

## 实例化必须保留的语义

- HFI 的初始化目前清空整个对象。Feedback 启动、缺电流以及 HFI 缺前区间电压均会复位历史。若系数随实例保存，这些路径只应清历史，不能在中断里重新计算比例或把系数清成零。辨识的工作区在开始和切换阶段都会清空，持续有效的系数应由实验对象持有，或由调用者传给需要它的叶。[Feedback 的 HFI 路由](../../motor/src/mfoc_feedback.c) · [辨识对象与阶段工作区](../../identification/include/mfoc_identification.h)
- 在配置边界检查可表示范围。Rs 的平均窗至少为 2 且为偶数，FIXED 的电流累加应满足现有 int32 上界。磁链窗限制为 1 至 4096，L 脉冲限制为 1 至 1024 个区间。若支持非整数电频率基值，需要保留其小数，明确相位系数和每拍角增量可表示的范围。各叶的限制应在启用对应实验时发挥作用。[Rs 窗约束](../../identification/src/mfoc_identification_rs.c) · [磁链窗约束](../../identification/src/mfoc_identification_flux.c)
- 改变 `fs` 时，8 拍载波的物理频率、64 组锁定时长、4 拍极性脉冲和 8 区间电感激励的实际持续时间会改变；改变 `fb` 时，同一速度 PU 所表示的转速会改变。默认参数逐拍一致只能证明迁移等价。其它节拍下的 PLL 调参、注入响应和可靠锁定要单独验证。[HFI 调参和调用契约](../../position/include/mfoc_hfi.h)

## 同配置的计算量对照

基线取自 2026-11-13 工作区（HEAD 为 `928e111`，包含尚未提交的前区间电压改动）。前后均用 Clang 19.1.5、Thumb、LUT 三角后端、`-ffp-contract=off`。在 Unicorn 中运行链接后的 Cortex-M0 FIXED 与 Cortex-M4F FLOAT 指令，计入实际调用的数学函数和编译器辅助函数。表格为每次调用的动态指令数；栈用入口 SP 与所测路径最低 SP 之差。M4F 使用单精度硬浮点 ABI。数据用于同一目标内的前后比较，未测 G431 实机周期、访存等待或完整 Motor ISR 的截止余量。

### 仅将 Ld/Lq 时间系数交给前台

现有电感叶的 `L_DT_PU` 已在编译期折叠。候选的目标是让同一份固件按实例选频率。临时原型在电感实验初始化时接收实际控制采样率 `fs`（整数 Hz）和电频率基值 `fb`（按后端标量表示的物理 Hz），计算无量纲 `dt_pu = (2π × fb) / fs`。前台拥有一个 4 B 标量，Ld、Lq 共用；20 B 的脉冲采样状态、采样函数和通用辨识对象的布局均沿用原实现。没有电感实验的调用方无需执行该初始化。当前公开辨识仍只允许启动 Rs，以下对照针对独立电感叶。[采样与前台计算](../../identification/src/inductance/mfoc_identification_inductance.c) · [公开辨识入口](../../identification/src/mfoc_identification.c)

候选的前台 `Finish` 按值接收已准备的系数。FIXED 保留原先先除以电流差、再按时间缩放的顺序。两个后端都用原公式的单精度运算顺序求系数，FIXED 再沿用原宏的正数舍入规则。采样仍为首拍记录初值、后续八拍累加实际区间电压和梯形电流。仓库中的三参数 `Finish` 是公开叶接口，如落地，需给已有调用方保留默认入口；本次测的是加入系数实参的候选入口。

默认 20 kHz / 400 电 Hz 对应 FLOAT 的 0.125663713、FIXED 的 4,118 个 Q15 计数。下表为 Clang 19.1.5 `-Os` 下单次叶函数的动态指令与该路径的栈峰值，含被调用的辅助函数。M4F 两栏均采用硬浮点 ABI。成功求值用 8 个完整区间、正向电流变化 0.25 PU、累计电压 4、累计两端电流之和 1 和 Rs 0.25 PU。尚无板上周期测量。

| 调用路径 | M0 FIXED 指令；栈 | M4F FLOAT 指令；栈 | M4F FIXED 指令；栈 |
| --- | --- | --- | --- |
| 初始化时间系数（每次配置一次） | 0 → 902；0 → 96 B | 0 → 24；0 → 0 B | 0 → 30；0 → 0 B |
| 普通采样 Step（每个有效区间） | 24 → 24；16 → 16 B | 20 → 20；0 → 0 B | 21 → 21；16 → 16 B |
| Finish 成功（前台，每轴一次） | 303 → 307；144 → 152 B | 36 → 35；0 → 0 B | 99 → 99；120 → 120 B |
| Finish 拒绝未满窗口 | 12 → 13；40 → 48 B | 5 → 5；0 → 0 B | 5 → 10；0 → 24 B |
| Finish 拒绝负电感 | 178 → 211；144 → 152 B | 30 → 29；0 → 0 B | 106 → 107；120 → 120 B |

三种目标分别以 `-Os`、`-O2` 编译，六组的采样函数机器码和重定位均逐字节相同，包含首拍和窗口结束分支。M0 FIXED 在 `-O2` 下成功 Finish 为 307 → 314 条，栈仍为 144 → 152 B。前台表值从叶函数入口计，只反映所列输入。调用者取得和传递参数的开销取决于布局：另以一个前台结构相邻存放 Rs、系数和输出，比较调用点，`-Os` 下 M0 FIXED 两版均执行 9 条指令，但调用者栈帧由 8 B 增至 16 B；M4F FLOAT 两版均为 5 条指令、0 B 栈。该试验没有改动 Motor。

M0 的 902 条来自首次运行时换算及边界检查，包括软浮点乘除和转换；Finish 和 Step 在 FIXED 下仍使用整数。M0 `Prepare` 函数本体为 124 B，单独作为链接入口时，其代码及所需运行库共 1,902 B。实际固件若已链接相同辅助函数，其 Flash 增量按最终链接计算。基线的系数准备为零运行时成本。若板上频率与基值总是由静态 profile 给定，可在 profile 中编译期生成同一系数，省去运行时准备；带系数的求值入口仍需按目标核对。

**数值回放。** 用 20 kHz / 400 Hz、10 kHz / 250 Hz、10 kHz / 375.5 Hz、20 kHz / 400.5 Hz 分别编译原版基线；同一候选按实际参数初始化。四组 FIXED 系数依次为 4,118、5,147、7,731、4,123。两后端共对照 320 次 Step（状态和返回码）、72 次 Finish（成功值或拒绝时保留的输出），均逐位一致。解析 RL 试验含 1.2 mH 和 1.8 mH、正反极性；最大相对误差为 0.932205%，与基线相同。[解析 RL 回归](../../tests/identification/identification_inductance_test.c)

四组配置的电频率均可精确表示。若原先的编译期基频有 Q15 无法保留的小数，换成 FIXED 实参会改变结果。例：10 kHz / 62.5341644287109375 Hz 时，基频先转为 Q15，系数从原版的 1,287 变成 1,288；正负脉冲回放分别对两种电感产生 +4、+5 个 Q15 计数的差异。候选在初始化时拒绝无效采样率、非正或不可表示的系数，失败时保留调用者的原值；还按采集区间数、输入界限和最小有效电流差限制 FIXED 系数，防止 Finish 的有符号 64 位乘积溢出。若要求与原浮点 profile 逐位相同，需在基频转入 Q15 之前生成系数。

**生产实现与验收。** 保留三参数 `Finish`，默认系数仍由编译器折叠。运行时系数由调用方在实验初始化时通过 `InitTiming` 算一次，两轴前台通过 `FinishPrepared` 使用。系数保存在采集状态之外，Motor、HFI 和 Rs 均无需初始化它。可选入口位于独立的编译单元，求值公式只维护一份。[默认电感叶](../../identification/src/inductance/mfoc_identification_inductance.c) · [可选时间系数与求值入口](../../identification/src/inductance/mfoc_identification_inductance_timing.c)

从最终源码重测 M0 FIXED、M4F FLOAT、M4F FIXED 的 `-Os` 和 `-O2`。每组的 Step、默认 Finish 的机器码、重定位以及作为独立链接入口得到的代码均与原版逐字节相同。M0 FIXED 的默认电感目标文件仅用整数辅助函数；可选 FinishPrepared 独立链接也只用整数。软浮点辅助函数只由 InitTiming 在运行时系数准备时使用。上表的动态路径指令数与栈峰值在最终实现中复现。[ARM 回归入口](../../tests/scripts/check_arm.ps1)

主机新增 32 kHz / 337.5 电 Hz 的双轴解析 RL 回归，单次 InitTiming 用于两次采集。给定 1.2 / 1.8 mH，FLOAT 求得 1.201085 / 1.800723 mH，FIXED 求得 1.200718 / 1.800509 mH。独立差分中，五组频率配置覆盖两个后端，400 次 Step 和 90 次默认 Finish 全部与各自专编的基线逐位相同。前述四组能精确表示基频的配置中，72 次可选 FinishPrepared 也逐位一致；第五组保留上述 FIXED 输入基频量化差异。已核对 8 与 1,024 个区间时的配置范围和失败时的输出保持。[主机回归](../../tests/identification/identification_inductance_test.c)

### 合并编译单元与函数级优化指令复核

补测 ARM Clang 19.1.5 的函数属性与 `#pragma`，候选均在临时目录生成，未修改生产实现。候选将两个 Finish 和 InitTiming 合入同一个 `.c`，求值公式仍为同一个内部 inline 函数。以 Unicorn 统计 M0 FIXED 的动态指令数，含整数运行库，栈为整个调用链的峰值；这些不是板上周期测量。

| `-Os` 候选 | 成功路径指令 | 负结果拒绝路径指令 | 成功路径栈峰值 |
| --- | ---: | ---: | ---: |
| 原版 / 当前分文件实现 | 303 | 178 | 144 B |
| 合并，无属性 | 306 | 210 | 144 B |
| 求值函数 `always_inline`，或默认入口 `flatten` | 306 | 210 | 144 B |
| 求值函数 `minsize` | 305 | 203 | 144 B |
| 求值函数 `noinline` | 313 | 217 | 160 B |
| 默认入口 `#pragma clang optimize off` | 320 | 224 | 176 B |

同时覆盖正向成功、反向成功、窗口未满、电流差过小和负结果拒绝五种输入，各候选返回码和输出均与基线一致。`-O2` 下合并版本的成功 / 负结果拒绝分别为 311 / 214 条，基线为 307 / 181 条；求值函数 `minsize` 虽把成功路径降到 306 条，负结果拒绝仍为 204 条。另测 `hot`、`cold`、默认或可选入口上的 `always_inline/noinline/minsize/flatten/optnone`，以及若干属性组合，均未满足所有已测路径不增加开销的要求。GCC 的 `__attribute__((optimize("Os")))` 在本工具链被诊断为未知属性，开启 `-Werror` 时编译失败。

对照优化后的 LLVM IR，原版先用常量反推商的合法范围，再在成功分支执行时间系数乘法；合并版本先做 64 位时间系数乘法，再检查乘积范围。强制内联没有恢复该常量范围优化，因此差异不只是函数调用开销。Clang 的 [`optnone` 与 `minsize` 属性](https://clang.llvm.org/docs/AttributeReference.html)以及 [`#pragma clang optimize`](https://clang.llvm.org/docs/LanguageExtensions.html)可以控制优化行为，但不能指定生成与原版相同的机器码。

保留当前分文件实现，公式继续只维护一份。此结论限于本次 Clang 版本、目标、优化级别和候选，不表示所有编译器或所有编译选项都无法合并。没有把存在开销增量的属性方案用于生产源码。

## 2026-11-15 磁链辨识的窗长与半拍角度

**P06 决定。** 窗长和半拍角度系数沿用编译期配置。P09c 接通磁链旋转采样时，再根据实际配置需求和完整采样路径复核实例化。以下实例数据保留为该次复核的对照。

默认窗长为 `floor(fs/10)`，可由 `MFOC_IDENTIFICATION_FLUX_SAMPLES` 显式指定，范围为 1 至 4,096 个有效区间。缺少前区间电压时跳过该拍。以默认整数频率 profile 计算，半拍系数为 `floor(2³¹ × fb/fs)`，单位是每 PU 电速度的 BAM32 计数。20 kHz／400 电 Hz 对应 2,000 拍和 42,949,672，16 kHz／250 电 Hz 对应 1,600 拍和 33,554,432。采样时由本拍角投影电流，由本拍角减去带符号的半拍增量投影前区间电压，反转时增量为负。前台 Finish 要求窗长恰好收满，且速度总和的绝对值达到后端表示的 0.05 PU 乘以窗长。默认 FIXED 门槛为 1,638 × 2,000 个原始计数。[采样与求值](../../identification/src/mfoc_identification_flux.c)

**临时候选。** 保留原默认入口，另编译可选入口。实验对象把窗长、按后端保存的半拍系数和最低速度总和紧邻 20 B 采样状态存放，共 32 B。三个值在前台 Prepare 写一次。Step 和 Finish 直接接收该实验对象。清采样状态时只清前 20 B。与早先的集中配置候选相比，这次叶函数没有额外的系数指针参数。当前 Motor 的磁链采样分派仍待 P09c 接通，下列采样数据从独立 Step 入口计起。

## 暂缓项与后续复核

1. **HFI 实例化暂缓。** 实例配置解决同一构建使用不同 `fs/fb` 的限制。M0 获取与有效第八拍均有指令增量，M4F FLOAT 的代价集中在极性静置和复位。后续如重启此项，需先确认这些路径的增量、实例 RAM 和 Init 的栈峰值。
2. **Rs 实例化暂缓。** 独立候选只保存五个 Rs 计数，共 20 B，不准备 L、磁链系数。连入分派后，辨识实例从 104 增至 128 B（FIXED）、96 增至 120 B（FLOAT），含填充均增加 24 B。仅算五个计数需要 M0 129 条、24 B 栈，M4F 28 条、8 B 栈，无软浮点。若沿用当前整对象清零写法，测完整辨识 Init 则是 M0 1,177 → 1,832 条、152 → 192 B 栈，M4F 1,084 → 1,378 条、128 → 168 B 栈。这是辨识 Init 自身及其辅助函数的开销。

   已重新编译测量此布局。两目标的对齐、采样和切档路径与上表集中配置相同：普通 Rs 采样 M0 94 → 99 条、M4F 63 → 65 条，两者栈峰值仍增加 8 B。20 kHz、10 kHz 下各后端的首次公开 Start → Step/Run → GetResult 结果与相应基线逐拍相同。另一项独立试验仅调整 Init 的清零写法，直接清目标对象并填入五个计数，完整 Init 测得 M0 1,047 条、M4F 644 条，各为 32 B 栈；这项改善限于初始化。
3. **电感与惯量。** 电感保留默认路径，可选前台开销已确认。惯量待算法接通后再决定所需配置。[Ld/Lq 单项验收](#p06-inductance-dt)

HFI 和 Rs 的实例化保留在临时候选阶段。真实电机上的注入响应、非默认速率的稳定性、完整 ISR 周期和 PWM 截止余量仍待台架实测。
