# P10 G431 台架 A/B 计时

2026-11-22，在 STM32G431 实机用 SWD、RTT 和固件内置计时器取数。使用原 P10 包 `p10-g431-20261122-001045-bbd8d503` 中的 8 份 HEX，逐份核对 SHA-256 并做烧录校验。固件为 170 MHz、20 kHz、debug-rel，关闭波形、原 ISR 统计与运行期母线更新。FLOAT Flux 用 `motor sensorless 0.4 0.05`，运行约 6 s，两候选均完成无感接管。FIXED HFI 用 `motor hfi start` 测获取期。每次停机后读 `p10`，对 RTT 输出未完整返回的记录，按匹配 ELF 的符号从 SWD 只读获取保存在 RAM 的快照。读取快照时三相输出均已关闭。

## 端点版 A/B

时间换算为 170 tick/µs。T 是固件根据 TIM2 锁存的 TIM1 更新事件推算的 ADC 触发参考点，I 是软件 IRQ 入口，W 是最后一次三相 CCR 写入并执行屏障后的打点，Esoft 是 ISR 软件尾标。U 是按候选推算的目标更新点。A 的 T→U 为 25.06 µs，B 为 50.06 µs。W−I 和 U−W 使用同一个最迟写入拍的原始时间戳计算。T→Esoft 单独取整轮最大值，尾标之后的异常返回未计入。

| 工况 | 候选 | 有效提交拍 | max T→W | 同拍 I→W | 同拍 U−W | max T→Esoft | 20% 初筛未达标拍 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| FLOAT Flux | A | 128,706 | 24.26 µs | 19.99 µs | +0.80 µs | 35.17 µs | 128,705 |
| FLOAT Flux | B | 136,897 | 24.68 µs | 20.14 µs | +25.38 µs | 35.11 µs | 0 |
| FIXED HFI 获取 | A | 10,000 | 43.32 µs | 38.74 µs | −18.26 µs | 49.72 µs | 10,000 |
| FIXED HFI 获取 | B | 10,000 | 43.61 µs | 39.05 µs | +6.45 µs | 49.97 µs | 1,020 |

FLOAT Flux 最迟写入发生在启动期。普通拍 max T→W 为 A 21.01 µs、B 21.24 µs，速度 PI 拍为 A 23.22 µs、B 23.67 µs。两者的计算耗时接近，B 的优势来自更长的写入窗口。B 通过此次 Flux 工况的 20% 初筛。

FIXED HFI 的两种端点版均在第 10,001 拍触发约 0.5 s 的锁定超时，挂起 Feedback 故障并关桥。各有 1 拍未写 PWM，前 10,000 拍可用于获取期分析。A/B 分别命中 608/1,025 次通过响应门槛的第 8 拍（`hfi_8_ok`）。最迟写入均来自这类拍。B 的最迟拍离 U 尚有 1,096 tick，但初筛要求 1,702 tick。即使用同拍 `Jseen`（T+905 tick）作为最有利的帧就绪上界，也至少要从该拍再省 425 tick（2.50 µs）才可能留出 20%；按初筛口径差 606 tick（3.56 µs）。HFI 尚无锁定后稳态或与速度 PI 同拍的实机数据。

## 分段版热点

取各分段版的最迟写入拍，以下是该拍 DWT 读数。Feedback 总时间包含位置外推与主观测器；子项仅用于定位。诊断插桩和统计也消耗时间，端点版用于余量比较。

| 分段 | FLOAT Flux A / B | FIXED HFI 获取 A / B |
| --- | ---: | ---: |
| Feedback 总计 | 6.67 / 6.70 µs | 21.14 / 21.21 µs |
| ↳ 旁路编码器位置外推 | 2.98 / 2.92 µs | 3.54 / 3.53 µs |
| ↳ 主观测器 Flux 或 HFI | 2.89 / 2.95 µs | 15.67 / 15.73 µs |
| Core 电流控制 | 5.28 / 5.21 µs | 10.94 / 10.95 µs |
| 电流读取与换算 | 0.97 / 1.02 µs | 1.05 / 1.08 µs |
| PWM 提交 | 1.54 / 1.58 µs | 1.27 / 1.30 µs |

Flux 配置里，旁路编码器和主 Flux 各约 3 µs。若继续优化，先验证旁路在当前主反馈下能否裁剪或移到 PWM 提交后。FIXED HFI 的最大单项是第 8 拍解调所在的 HFI 步进，其次是 Core。现有分段到函数级，仍需拆测才能确定 HFI 内部宽除法、角度计算各占多少。分段版 FIXED HFI 的最迟软件尾标为 A 56.17 µs、B 56.82 µs；端点版为 49.72、49.97 µs。分段版的 `tail_miss` 分别为 617、984，比较基准是推算的下一触发点。这个标志用于提示探针开销与重拍峰值，完整 ISR 异常返回和下一双 JEOS 的最终余量仍待核对。

## PC 端证据与待验证项

- 八份固件均报 `locked=1`、`failures=0`、`u2-u1=8500` tick、`nvic_ok=1`。运行时没有 `gap`、`phase_invalid` 或 `adc_incomplete`。停桥轮询每份得到 16 个联合 JEOS 观测、0 拒收。八组下界最小值和上界最大值合并为 T+593～685 tick（3.49～4.03 µs），最宽单帧观测界 49 tick。NVIC 读到 ADC 为 1、DMA/Break 为 2、SysTick 为 3、UART 为 4，符合候选预设。
- TIM2 捕获和启动握手支持内部更新事件时序。**三相 PWM 实际生效相位、ADC2 Rank 2 的 V 相模拟采样有效性仍待验证。** 双 JEOS 只能确认软件在读取时见到两个标志，无法证实低侧导通窗口覆盖采样孔径。
- 本轮结论限于 FLOAT Flux 启动及运行、FIXED HFI 获取期。其余数值组合、SMO 测速窗、限幅和辨识拍未上板。本轮保持电压历史模型及控制代码原样，A/B 尚未正式定型。

原始 RTT、烧录校验及 RAM 快照保存在 `artifacts/p10-g431-20261122-host-only/`。已排除一次 RTT 重连造成的无完整运行记录（`B-endpoints-float-flux-RTT-retry.log`），表中 B 使用随后完成的一次运行。板上最后留有 B 的 FIXED HFI 分段版，停在 HFI 超时后的故障状态，三相输出已关闭。
