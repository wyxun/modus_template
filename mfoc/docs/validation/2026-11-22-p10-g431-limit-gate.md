# P10 G431 限幅组合拍复测

2026-11-22。G431 最终 B，2804 空载，12 V / 0.5 A 限流，20 kHz 采样。沿用端点探针，单独开关由低优先级 TIM2 比较中断实现的退出见证。安全限流保留，诊断命令在 SMO 已捕获并接管角度时，稀疏地把单拍 Core 电压圆半径降至当前有效值的一半。两种速度环相位由同一 ELF 的诊断命令选择。错峰时速度 PI 仍每 20 拍执行一次，首次相位调到 SMO 测速窗之后一拍。没有单独做纯限幅实验。

所有时间以 ADC 触发参考点 `T` 为起点，单位为 170 MHz 定时器 tick。末次 CCR 写入的门槛是 `W−T ≤ 6705`。启用退出见证时，TIM2 仅在 ADC ISR 退出且其 NVIC 活跃位清除后采到 `E⁺`，要求 `E⁺−T < 8436`。该点比下一次 ADC 触发提前 64 tick，也早于下一完整帧。表内各列取所在运行的独立峰值。

FLOAT 原实现有退出见证，命中 44 个限幅拍，其中两拍叠加母线更新、速度 PI 和 SMO 测速窗，写入最大 4846 tick，退出见证最大 6902 tick。FIXED 原实现去见证后命中两次四项同拍，四项组合的最迟写入为 7049 tick，全运行的最迟写入为 7051 tick。错峰消除了速度 PI 与测速窗同拍，原限幅仍超写入门槛，带见证复测有一次退出晚于 8436 tick。

组合候选的无见证有效复测覆盖 154,817 拍。`母线 + 限幅 + 速度 PI` 与 `母线 + 限幅 + SMO 测速窗` 各命中三拍，末写最大分别为 6356、6396 tick。最迟写入留 309 tick（1.82 µs）。有见证复测覆盖 154,933 拍，两类组合分别命中三拍和两拍，全部退出见证配对，最大 8212 tick，距守门线留 224 tick（1.32 µs）。这次有见证固件的整轮末写仍超 6705 tick，以无见证固件验写入，以有见证固件验退出。两轮 `nvic_ok=1`，均无丢帧、相位错误、ADC 缺帧、未提交 PWM 或故障。另有若干尝试在无感起步超时，未计入达标证据。

## 数值与代价

圆形限幅保留向上取整的模长 `n` 以及有符号向零截断。超限时正半径 `r < n`，两轴幅值都不超过 `n`。`n ≤ 46341` 时，`|axis × r| ≤ 46341 × 46340 < INT32_MAX`，可以直接做原有两次 32 位除法。更大的模长保留两次宽除法。主机对照 2,002,025 组输入逐位一致，G431 链接 ELF 的 13 组 `mfoc_core_Step` 回放中，全部输出与 Core 状态也逐位一致。

| G431 FIXED，按链接 ELF 回放 | Core `-Os` 原实现 | Core `-O2` 加窄除法 |
| --- | ---: | ---: |
| 普通拍指令，三组输入 | 599 / 632 / 717 | 602 / 635 / 720 |
| 常用母线范围内限幅，三组输入 | 958 / 968 / 970 | 833 / 843 / 845 |
| 软件栈，普通拍 / 常用限幅拍 | 120 / 176 B | 112 / 112 B |
| 固件 Flash `text + data`，无退出见证 | 56024 B | 56480 B |

同为 `-O2` 时，窄除法自身在三组普通拍的额外指令为 0，常用限幅拍各少 114 条。单独在 `-Os` 下使用窄除法，三组普通拍各多 2 条，常用限幅拍各少 114 条。上述指令和软件栈仅覆盖 Core 及其子调用。Flash 来自两份诊断固件，生产配置的差值待转正验证。

转正前，组合候选仅走诊断开关。该阶段重新构建的 G431 FLOAT/FIXED release HEX 与最终 B 集成基线逐字节一致。写入和退出结果用于评审普通拍的额外指令代价，发布路径的验收见下一节。

原始 RTT、固件、分组统计和退出见证位于 `artifacts/p10-g431-close-20261122-112040/`。两组有效组合复测分别是 `limit-fixed-div32-o2-staggered-0-r2` 和 `limit-fixed-div32-o2-staggered-1`。结束后读取 `TIM1_CCER=0x00001000`，三相输出关闭。

## 发布路径复测与关单

2026-11-22 确认代价后，仅 G431 FIXED 启用窄除法和 Core 单文件 `-O2`。SMO 为主反馈且测速窗等于速度环分频时，Motor 在无感接管速度环时初始化一次相位，速度 PI 固定在 SMO 测速窗的下一拍。台架 `p10 limit` 只降低预定拍的电压限幅半径，没有写速度分频计数或 SMO 窗口状态。

退出见证的首三轮沿用 TIM2 比较中断。第三轮在 110,000 个配对中两次越过 8436 tick，最迟 8445 tick，发生在限幅恢复与速度 PI 同拍。旧原始数据保留。后续探针在 ADC 尾部设置低优先级 TIM2 IRQ pending，去掉入口的比较配置和待处理中断清理。仍以 TIM2 入口计数与 ADC 活跃位清除为实际异常退出上界。记录中的 `compare` 在新版本表示软件请求时标。回放覆盖定时器回绕、守门线、丢配对、错误优先级和 ADC 仍活跃的情况。8436 tick 门槛不变。

| 去退出见证，写入验收 | 167,492 | 41 | 3 / 2 | **6399** | — |

写入验收比 6705 tick 门槛早 306 tick（1.80 µs）。退出验收三轮共 387,382 个见证全部配对，零超时。最慢一拍比 8436 tick 保守线早 39 tick（0.23 µs），比下次触发参考早 103 tick。带见证第三轮末写多 3 tick，全量末写仍按去退出见证版判定。各轮速度 PI 与 SMO 测速窗同拍数为零。NVIC 优先级核验通过，缺帧与相位错误为零；软件挂起版两次重启各有一次无感起步超时保护，其关断帧也纳入退出验收，无见证写入轮及软件挂起冷启轮无故障。

P10 实时性门禁关闭。2804 的 HFI 锁定、旋转辨识及电感重复性继续归 P09，第二功率板实机验收仍归 P12。G431 默认 FIXED release 的 Flash 增加 452 B，数据与 BSS 持平。G431 FLOAT 与 AT32F413 FLOAT/FIXED release HEX 和阶段 3 基线逐字节一致。发布构建关闭时序和限幅测试开关。

复测固件、RTT 与全部退出快照位于 `artifacts/p10-g431-release-gate-20261122-115057/`。旧比较见证在 `with-exit-r1` 至 `with-exit-r3`，软件挂起见证在 `pended-exit-r1` 至 `pended-exit-r3`。
