# P09 无编码器辨识的软件验收

2026-11-19，本地工作区。四种操作均经公开的 `Start → Motor Start → Step/Run → GetResult` 路径运行。测试使用真实 Motor、Core 和辨识实现，功率级由软件代替。实机精度、重复性和 PWM 截止时间留待台架测量。

## 实验条件和独立模型

软件功率级使用 PWM 实际提交的三相占空比、12 V 母线、电气和机械方程计算下一拍三相电流。测试先用解析 RL 阶跃核对积分器。转子角度和速度只在测试侧用于推进和核对物理模型，四种操作均可编译掉位置 Port。旋转负载只有转子和黏性摩擦。[电机模型与公开入口回放](../../tests/motor/motor_identification_plant_test.c)

下表来自同一 Motor 的三次连续启动。五个参数的初值都有偏差，第一次测 Rs/Ld/Lq，第二次使用第一次的结果测磁链，第三次使用第二次的结果测惯量。每次旋转实验从自由、静止的轴开始，三次均正常关 PWM，运行模型保留原参数。表内采用 SI 单位，代码内传递 PU。

| 参数 | 模型真值 | FLOAT | FIXED |
| --- | ---: | ---: | ---: |
| Rs（Ω） | 2.75000 | 2.75000 | 2.75035 |
| Ld（mH） | 0.80000 | 0.80222 | 0.80224 |
| Lq（mH） | 1.02000 | 1.02174 | 1.02276 |
| 磁链（mWb） | 3.90000 | 3.89432 | 3.89310 |
| 空轴惯量（10⁻⁶ kg·m²） | 4.7000 | 4.6932 | 4.6373 |

串联工况峰值电流 FLOAT / FIXED 为 0.099740 / 0.099736 PU，最高真实电角速度为 146.593 / 145.848 rad/s。另有 11 个独立场景，覆盖 2804 标称绕组、单测 Rs、两轴不同电感、自由轴、初始正反转、堵转，以及采样期间外部强制 +230 或 −110 电气 rad/s。后两种工况均撤压关断且拒绝发布结果。另在 Lq、磁链和惯量采样阶段主动取消，三者均回到 IDLE，并保留调用方的结果缓冲区。测试代码用独立模型真值捕捉回归，库中没有这组真值或实机精度合格线。

## 接口和保护

- `RESISTANCE` 和 `ELECTRICAL` 需要转子静止。测电感时，转子须保持在对齐后的 d 轴。电感通过连续八个 PWM 区间测量；任一区间的模型电压缺失即退出。电流变化给出轴向电感，受试轴若偏转会改变投影。零速阶段无法仅凭反电动势验证轴已固定。
- 原 Rs 高档为 0.09 V/Vdc。12 V、2.55 Ω、3.5 A 基值的标称 2804 回放在第 12,040 拍触发 0.12 PU 限流。现在两档为 0.04 和 0.08 V/Vdc，标称峰值降至约 0.10756 PU。名义电压阶跃从 0.05 减至 0.04，相应的最小电流差从 0.020 调为 0.016 PU，保留原来的名义阻值范围。同一实例连续测 1、2、2.4 PU，各次两档均重新采满 6,000 帧；带偏置和母线波动的回放另外覆盖两档的最小电流与稳定性。[Rs 数值回归](../../tests/identification/identification_rs_test.c)
- 旋转实验只使用本拍电流和前区间电压。在默认 20 kHz 下每 32 拍合成一个 1.6 ms 观测窗，从窗口电压减去 Rs 压降和 Lq 电流变化项，依据反电动势相位变化估速。起转目标为有效速度上限的 58%，稳定约 100 ms 后才开始采集。磁链使用约 120 ms 数据并补偿 Ld/Lq 的差异。测惯量时在相同正转速度区间制动与加速；两段平均转矩之差消除相同的阻力矩。窗口和时间系数均按编译期 profile 计算。[旋转观测与磁链](../../identification/src/mfoc_identification_rotation.c) · [惯量求值](../../identification/src/mfoc_identification_inertia.c)
- “200 电速度”在本实现中取 **200 电气 rad/s**，约 31.83 电 Hz。电机设置了更低的正转速上限时，按更低值执行。保护对观测窗的估计生效，观测建立和更新均有延迟。电流每拍检查，两轴绝对值之和同时受 0.12 PU 和实例 `i_max` 约束。越限当拍直接回中性，下一次前台 Run 关 PWM。旋转失锁、缺采样、超时、取消或 IO 失败按已有语义退出。前台判定超时后先发布中性路由，即使中断抢在物理关断前进入也只会提交中性。成功求值后的 PWM 关断错误单独锁存，成功结果仍可读取。[Motor 限额和停机回放](../../tests/motor/motor_identification_test.c)
- 所有操作沿用既有 Start/Stop/GetResult 接口。独立调用 `mfoc_identification_Step` 可直接用其返回值区分虚拟 dq、直压和空闲。正常运行的电流参考和模型参数不由辨识覆写。调用方可把结果传入下一项实验；如需修改运行模型，仍须在停机时显式调用 P08 的 ApplyModel。

## G431 指令和栈

基线为本批修改前的工作区快照，含已完成的 P09a 电流保护。G431 release、Clang 19.1.5、Cortex-M4F 硬浮点 ABI、`-Os`、LUT、20 kHz、HFI 关闭。正常路径使用 POSITION 主反馈和测试 Port；辨识旁路 Feedback。ARM 模拟从 `mfoc_motor_Step` 入口运行到返回，统计实际执行指令和入口 SP 至最低 SP 的字节数，每次计数前清除模拟器翻译缓存。数据不含外围 IRQ 包装、板级采样延迟或硬件周期，重拍为已覆盖路径。
