# P10 阶段 2.3 · G431 HFI 第八拍

2026-11-22，在既有 2804 空载台架上测 G431 候选 B。170 MHz、20 kHz、`-Os`，四份 FIXED 端点固件和一份 FLOAT 端点固件均已裁掉旁路位置外推，关闭波形及运行期母线，保留前台编码器 I²C。FIXED 基线与阶段 2.1 裁剪版 HEX、ELF 逐字节相同。四个 FIXED 版本构成 2×2 对照，仅替换 HFI 对象。端点固件不带本轮的 DWT 分段探针。

## 旧版除法与 CORDIC 的片上周期

在 FIXED 诊断固件中，对三次宽除法和 CORDIC 调用分别用 DWT 打点。反汇编确认凸极阈值调用 `__aeabi_uldivmod`，两次坐标归一化调用 `__aeabi_ldivmod`，与原端点版一致。每个括号含调用和子函数返回，除法分子乘积、归一化传参及统计发布均在括号外。CORDIC 括号含保存输出指针的一条 MOV。以下为 1014 个通过凸极门槛的第八拍，空括号为 1 周期，表中保留原读数。

| 分段 | 最小 / 平均 / 最大周期 | 平均耗时 |
| --- | ---: | ---: |
| 凸极比除以 `trace` | 106 / 522.1 / 566 | 3.07 µs |
| Y 分量除以 `magnitude` | 172 / 454.0 / 494 | 2.67 µs |
| X 分量除以 `magnitude` | 130 / 404.4 / 452 | 2.38 µs |
| CORDIC `atan2` | 380 / 388.5 / 409 | 2.29 µs |

三次除法的平均合计为 1380.5 周期（8.12 µs）。各段最大值可能来自不同拍。第一份分段固件把凸极阈值调用编成有符号入口，保留在原始日志中，以上数据取后来与原端点版匹配的入口。

## 算术等价、角度与锁定

- 前置判断保证 `trace > 0` 且原 Q15 商不超过 65536。令 `N=magnitude×32768`，整数门槛为 `T`，则 `floor(N/trace) < T` 严格等价于 `N < T×trace`。按 HFI 接口 |i|≤1、|u|≤4 PU 的上界，两边都有带符号 64 位余量。100 万宽矩阵和 393,111 个门槛邻点中，接受位和仅替换门槛时的角度均逐位一致。
- 内建 FIXED CORDIC 用重缩放后的 32 位方向向量。较大的分量超过 `INT32_MAX` 时，按其最高有效位给两分量右移相同位数，最多 7 位。超过 100 万个向量覆盖四象限、近坐标轴和移位边界，移位方案相对原版的 d 轴角最大差 **0.010986° 电角**。FLOAT 100 万矩阵逐位一致。FIXED 外部 `atan2` 保持原归一化 Q15 参数，启用极性判别时的脉冲除法仍保留。
- 正、反 0.8 电 Hz 和 128 个静止角的主机模型中，旧版及候选均在第 512 拍锁定，最大跟踪角差 **0.021102° 电角**。极性打开时，两半周强响应均在第 1468 拍有效，模糊极性拒绝。另覆盖弱响应、缺激励、备用电机配置、FLOAT/FIXED 通道与外部数学后端。
- 实际 ARM ELF 的 80 条 IRQ 路径回放包含普通拍、第八拍、速度 PI 碰撞、宽向量和拒绝分支。双优化普通拍的指令及软件栈持平，非零但低于凸极门槛的拒绝拍少 233 条指令，零凸极拒绝拍多 3 条，缺激励持平。

## 独立因素的端点实测

`I→W` 是最迟写入拍从 IRQ 入口到末次 CCR 提交的周期，`I→Esoft` 是最迟软件尾标拍的同拍周期，含写 PWM 后的工作。尾标后的异常返回另计。两列各从相应帧的原始计数相减。软件栈是链接 ELF IRQ 回放的最低 SP，含算术库调用，硬件异常压栈和系统嵌套峰值另计。

| 运行固件 | 第八拍通过凸极门槛 | 第八拍宽除法 | 写前周期 `I→W`，相对 FIXED 基线 | IRQ 至尾标周期 `I→Esoft`，相对 FIXED 基线 | Flash | 软件栈峰值 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| FIXED 基线 | 1019 | 3 | 5872 | 6966 | 52,348 B | 384 B |
| FIXED 仅乘法比较 | 1029 | 2 | 5440（−432） | 6528（−438） | 52,340 B（−8） | 384 B |
| FIXED 仅共同移位 | 986 | 1 | 4973（−899） | 6067（−899） | 52,388 B（+40） | 344 B |
| FIXED 两项合用 | 1000 | **0** | **4402（−1470）** | **5750（−1216）** | 52,396 B（+48） | **304 B** |
| FLOAT HFI 基线 | 1030 | 原生浮点 | 3662 | 4821 | 52,716 B | 280 B |

双优化在实机写前省 **8.65 µs**，IRQ 至最迟尾标省 **7.15 µs**，相对 FIXED 基线分别减少约 25.0% 和 17.5%。最迟写入为 T+5177 tick，距 B 更新点 3333 tick（19.61 µs），FIXED 基线则为 1871 tick（11.01 µs）。双优化在匹配用例里消除了第八拍轴提取的 3 个宽除法调用。两个单因素的差额仅对各自运行有效，Flash 布局和输入变化都会影响端点周期。

FLOAT HFI 单独启用时的写前为 **21.54 µs**，IRQ 至最迟尾标为 **28.36 µs**。最迟写入距更新点为 4072 tick（23.95 µs）。FLOAT HFI 与 Flux 同时运行的预算仍需做同拍实测。

五组均成功提交 10,000 拍，20% 写入初筛未达标为 0，超过下一推算触发时刻的尾标为 0。五组均未在 2804 上锁定，第 10,001 拍超时，记录一次未提交并由 Feedback 故障关断。各组的有效解调命中数来自不同采样，判定等价取相同输入的离线对照。无采样间隔跳跃、无效相位或双 JEOS 不齐。试验使用候选 B 的定时器相位和原电压历史，锁定之后与速度 PI、限幅、母线的新帧碰撞仍属后续矩阵。

## 现场与交接

一次基线启动发生编码器 SDA 保持低电平，Motor 没有初始化。台架断电恢复。一次运行态 OpenOCD CRC 校验占用了 RTT 所在的 RAM，改用关桥时读取 Flash 并在主机逐字节比对，复位后恢复 RTT。一次滞后的启动回包用片内帧计数和停机快照核对，正式分段记录有 1014 个有效第八拍。无有效控制拍的启动尝试未计入表格。
