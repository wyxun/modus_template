# MFOC V1 支持矩阵和验收条件

本表以 `cf50772` 为代码基线，记录 2026-11-23 已有证据和最终候选需要
复测的条件。证据分别记录为实机、目标 ELF 回放或主机测试。发布结论按
板、具体构建和电机填写。窗口、负载或转速缺少证据时保留待验收状态。

## 平台与闭环

| 平台与电机 | 计划纳入基础闭环验收的配置 | 已有证据及范围 | 最终候选还需确认 |
| --- | --- | --- | --- |
| STM32G431，2804，空载，12 V，电源限流 0.5 A | FLOAT、FIXED，20 kHz 电流环、1 kHz 速度环，Flux 或 SMO。TIM1 顶部采样、下一顶部装载 | 最终 B 台架实测覆盖两种后端的启动、接管、稳态和时序。FLOAT Flux 有 20 次冷热启停和约 31.3 s 连续运行记录。FLOAT SMO 在 180 电 Hz 取得整圈 KCL 数据，最大调制 0.3791，V 相最大占空比 82.64%。FIXED SMO 的限幅、速度 PI、母线更新等重拍已作时序关单 | 对照最终固件。逐构建记录正反向速度、相电流、负载与调制范围。目前 180 电 Hz 的采样间接证据只适用于该 FLOAT SMO 工况 |
| STM32G431，2804，编码器 | POSITION 反馈保留在库和目标工程 | 编码器角度采集、外推、校零和波形同拍复用已有软件及板上诊断证据 | 若把 POSITION 主控列为正式实机组合，需有对应最终固件的闭环、启停、故障和同拍时序证据 |
| AT-MOTOR-EVB V1.1 / AT32F413RCT7，BLDC5562D048，24 V | FIXED + Hall，20 kHz 电流环、1 kHz 速度环，2 对极 | 已有实测 Hall 扇区表与诊断固件的速度闭环记录。24 V 构建的开桥母线窗口为 18～30 V | 用常规项目固件确认 ADC 帧、闭环启停和 Break，再验 PWM 装载、采样有效性及最终时序。按最终实测填写速度和调制范围 |
| AT32F413，其余配置 | FLOAT Hall、运行期母线更新、12 V 非 Hall 保护回放 | 编译及相关软件回放 | 每增加一项正式实机组合，需对应台架证据 |

G431 的采样相位与 KCL 记录来自片内时标和电学响应。现有数据没有覆盖
额定负载、持续堵转或全调制范围。

## 诊断功能与辨识

| 功能 | 已有证据 | 当前发布边界 |
| --- | --- | --- |
| HFI，FLOAT/FIXED | G431 获取期与解调峰值时序已测。2804 在诊断注入升至 0.12 PU 后仍未锁定。自由轴漂移使实际转子角覆盖不足 | 2804 暂不执行 HFI 锁定验收。已锁定跟踪、速度 PI 与限幅组合之后用另一台电机验证。2804 固有凸极率还未定量确认 |
| EKF，FLOAT | G431 20 kHz 完成接管和运行，稳态角差约 +16.2 电度。一次冷启见证超保守退出线 8 tick | 诊断配置。还需查角差、冷启退出及堵转恢复，完成前不给出正式闭环承诺 |
| Rs，FLOAT/FIXED | G431 2804 实机取得结果并覆盖取消和保护。测量含板级视在压降，部分轮次因低档稳定性拒绝 | 保留台架记录。对照参考测量和重复性后给出精度声明 |
| Ld/Lq，FLOAT/FIXED | 每轴 8 对正负脉冲已定稿，两后端均取得实机结果。实测激励区间 128 拍，绝对值尚无独立参考 | 保留 8 对实现，台架数据报告测值及重复性范围。绝对精度待独立对照 |
| 磁链、惯量，FLOAT/FIXED | 软件回放通过。G431 2804 在升速阶段触发估速保护，Rs 为 3.80 Ω 时仍未进入测量窗 | 待实机完成并验证重复性。未有可用实测参数；不以软件回放替代实验 |
| 运行期母线更新 | 两板有软件碰撞回放。G431 有 SMO 模型的重拍台架记录 | 默认关闭。AT32 实机及额外组合按实际纳入范围验收 |

## 最终候选验收条件

| 项目 | 通过条件及记录 |
| --- | --- |
| 构建身份 | 记录代码版本、是否有未提交改动、HEX SHA-256、工具链、优化选项、目标、电机与反馈配置。轴上负载、电源、电流限制和测量设备随每组结果保存 |
| 启停和保护 | 候选的正式实机组合覆盖冷启、热重启、启动取消、反馈接管或 Hall 起动、限幅及恢复。记录有效帧、失败原因和输出状态。Break 触发后硬件关闭输出，故障源解除仍需按板级契约显式恢复 |
| 写入和退出 | 帧就绪至末次写入 ≤ 实测截止窗口的 80%，异常返回早于下一完整帧就绪。G431 既有上界为触发参考到末写 ≤ 6705 tick、退出见证 < 8436 tick。将入选工况实际碰撞的速度 PI、观测器峰值、限幅和启用的母线更新纳入统计 |
| 采样和 PWM | 连续帧核对触发周期、缺帧、装载相位及先前区间的电压归属。单拍脉冲指纹和三相 KCL 用于间接验证。分开记录采样窗覆盖的最高调制和最高相占空比 |
| 接管和精度 | 依据速度、方向、负载、电流和参考角度记录结果。每个正式组合给出有效角度、速度、稳态和恢复的判定口径。辨识精度按独立参考及重复测量核对，未定的数值门槛须在验收前确认 |
| 独立交付 | 从实际导出包复跑 FLOAT/FIXED 独立构建、示例和配置错配负测。通过口径与支持矩阵一致。发布前确认正式版本、许可证及分发范围 |

当前表保留原 V1 门禁。磁链、惯量和 HFI 的台架缺口、AT32 第二功率板
验收以及交付版本与许可证仍待关闭。若首发改为只承诺基础闭环，应先更新
原计划的功能范围和门禁，再按本表锁定相应构建。
